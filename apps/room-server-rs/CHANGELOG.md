# 变更记录

本文件只记录独立房间服务器（`apps/room-server-rs`）的发布；它和游戏 / 桌面版共用仓库，但版本和发布标签独立（`room-server-v*`）。

## 0.2.0（未发布）

面向公网联机对局；旧客户端的进房/状态/照顾协议不变。

- 新增 `--authority-url` / `--authority-secret`：把房间里的游戏事件转发给 `room-authority`，支持左轮 1v1 开局、结算和替沉默一方判负；不配这两个参数时公网房间只能进房、不能开局（客户端会提示）。
- 持久房间（默认）按加入顺序把第一位玩家当作开局房主，房间是否存活仍由服务器决定；非持久房间仍是房主离开即关房。
- 房间协议新增游戏事件通道，公网权威只接受该房间 owner 的开局请求。
- 部署公网权威联机时，房间服务器和 `room-authority` 必须使用同一个 `--secret`，权威进程只监听回环地址。
- Linux x86_64、aarch64 预编译包；升级前先看 `--help` 确认权威参数已存在。

## 0.1.0（2026-11-17）

首个独立预编译发布。

- 单个 Rust 二进制，不依赖 Node.js、Electron、OpenSSL 或数据库。
- 线协议与桌面客户端 / `apps/desktop/lib/room-server.js` 兼容；本次发布不改客户端协议。
- Linux x86_64、aarch64 预编译包，附 `SHA256SUMS`。
- 新增 `--version` / `-V`，显示 crate 版本和构建目标。
- 提供 systemd、Caddy、Nginx、Docker 和直接 HTTPS 部署说明。
- 一个进程托管一个内存房间，默认持久；重启后玩家列表、房间码和照顾事件清空。
