# 睡姿小猪：续画提示词

以下是**依据第三版已确认图片整理的复用稿，不是历史逐字原文**。已确认的游戏图片是 `assets/*-sleep.png`，素材工作区原尺寸图在 `dsh-piggy-artwork/sleep-mat/rework-v3/`，总览是 `sleep-poses-contact-sheet-v3.png`。参考用户最初的 `sleep-mat/reference-original.png`，并同时提供本角色现有立绘和第三版睡姿图。先延续第三版姿势再做局部修改，不重新发明猪的身体结构。

## 通用提示词

> 参考所给最初小猪睡垫图、该角色立绘和已确认的第三版睡姿，生成同一角色的 Q 版侧卧睡姿 PNG。保留最初参考图那种软萌、简洁、轻微手绘感的比例和表情：圆润鼻子、小耳朵、短腿、自然蜷起的身体，睡得安稳。猪的身体真实地压在蓝色云状睡垫**上面**，睡垫从下方托住猪，接触点、遮挡和影子一致；不要把垫子画成猪背后的背景。保持角色原本的体形、颜色、衣服、帽子和道具，衣服沿身体表面正确包裹，不漂浮、错位或穿模。整张图完整入框，四肢数量准确，透明背景。画面偏 Q 版，不增加写实毛发、复杂纹理和真实摄影光影。只生成一只猪及睡垫，不加文字和无关道具。
