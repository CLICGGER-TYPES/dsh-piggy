# 皮肤包格式规范

[文档中心](../README.md) · [玩家换肤教程](skins.md) · [制作教程](creating-skins.md)

本页记录导入器实际执行的格式与安全限制，适合皮肤作者和工具开发者查阅。

## ZIP 限制

- 整个 ZIP 最大 2 MB。
- 最多 20 个文件。
- 文件必须直接位于 ZIP 根目录。
- 只接受未压缩或 Deflate 压缩，不接受加密 ZIP。
- 文件只能是 `skin.json` 或名称由小写英文字母组成的 `.png` 或兼容的 `.svg`。
- 每个解压后的文件最大 96 KB。

## 场景文件

必需场景：`idle`、`eat`、`bathe`、`play`、`pet`。

可选场景：`relaxed`、`work`、`study`、`trip`、`fish`、`sleep`。前五种缺少时回退到 `idle`；缺少 `sleep.png` / `sleep.svg` 时，打盹显示默认小猪睡姿。`sleep.png` 是横躺睡觉的专用图，与放松时的 `relaxed.png` 不同。

## skin.json 字段

| 字段 | 必需 | 限制 |
|---|---:|---|
| `key` | 是 | 1–24 位；小写字母、数字、短横线；首尾必须是字母或数字；不能与默认或内置皮肤重名 |
| `label` | 是 | 非空；导入时最多保留 30 个字符 |
| `author` | 否 | 默认“玩家”；最多保留 30 个字符 |
| `description` | 否 | 最多保留 100 个字符 |
| `emoji` | 否 | 默认 `🎨`；用于皮肤列表标识 |
| `contact` | 否 | 摸摸手落点，`{ "x": 0–1, "y": 0–1 }`；两个都必须是有限数字，否则整包拒收 |

同一个自定义 `key` 可以再次导入，用于更新已有皮肤；导入成功后当前显示会立刻换成新图、重新取景，不用整页刷新。

## 摸摸手接触点（可选，旧包不用改）

摸摸小猪时，那只独立的高清小手默认按「可见边的上沿中点」找落点。头顶有高帽子、大光环，或者图里留了大量透明包边的皮肤，自动估计会落在帽尖或空气里；这时可以在 `skin.json` 里写一个接触点：

```json
{ "key": "berry", "label": "莓果猪", "contact": { "x": 0.5, "y": 0.12 } }
```

- 坐标系是**立绘方框**：`x` 0 是左边缘、1 是右边缘，`y` 0 是上边缘、1 是下边缘（y 向下），和自动估计、透明边界是同一套坐标。导入器会按透明部分自动取景放大居中，坐标按**原图的立绘方框**给，取景（含「小猪大小」缩放）由游戏换算，不用自己算。非正方形图先等比缩进方形立绘框（按短边留透明），坐标按缩进后的方框算，和换肤页校准方框里看到的一致。
- 它描述的是**站立立绘**的落点；打盹/困了用的是睡姿图，本来就不播摸摸手。
- 只有两个都在 `[0,1]` 里的有限数字才算合法；写错的包直接被拒（错误里会点名 `contact`），不会出现「声明了却没生效」。写 `null` 等于不声明。
- 没有这个字段的旧 PNG/SVG 包行为完全不变：还是自动估计，默认猪和没校准过的内置皮肤也一样。

玩家也可以在**换肤页**给当前皮肤（内置特殊外观、导入皮肤都行）自己校准：拖方框里的落点，手会当场跟着落，「恢复自动」回到自动估计。这个校准**只存在本机**（`localStorage` 的 `dsh-piggy:skin-contacts`），不进养成存档、不花钱、不改已有造型、不改别人的存档。皮肤包里的 `contact` 是作者给的默认值，本机校准优先于它；`contact` 在导入时记在本机，换设备重新导入即可恢复。

## PNG 限制

- 完整 PNG 文件，带 alpha 通道或透明调色板；推荐长边 256px，最多 1024px。
- 不要求正方形：非正方形图按等比缩放显示（不拉伸），显示高度仍按透明部分统一校准；量图、取景和摸摸手用同一套算则。
- 单张仍最多 96KB；同一动作只能放 PNG / SVG 的一种。
- 导入不会修改存档结构，文件格式由存档旁边的实际图片决定。

## 旧 SVG 兼容限制

- 根文档必须包含 `<svg>`。
- 必须使用 `viewBox="0 0 64 64"`；数字之间可以使用空格。
- 禁止 `script`、`image`、`text`、`use`、`style`、`foreignObject`。
- 禁止 `linearGradient`、`radialGradient`、`filter`。
- 禁止 `DOCTYPE`、实体、`href`、`src`、事件属性和 `url()`。

这些限制让皮肤保持为可审查的纯矢量路径，并阻止脚本、外链资源、字体和位图进入页面。

## 安装与显示规则

- 导入器先校验整个包，失败时不会安装其中一部分。
- 皮肤文件保存在存档文件旁边的 `skins/` 目录。
- 导入成功后皮肤立即加入列表并成为当前皮肤。
- 显示优先级为“晋升形态 → 当前皮肤 → 默认猪”。晋升形态结束后会恢复之前选择的皮肤。
- 皮肤字段由 `ensureSkins(state)` 为旧存档补齐，不需要提升存档版本。
- 设置中的“小猪大小”使用同一比例（减号、百分比输入、加号）控制普通猪、导入皮肤和睡姿；导入的 PNG / SVG 首次加载时按透明部分的可见高度校准显示大小，不修改原文件。
- 摸摸手的既有语义不变：9% 最大受压、5 帧 × 60ms 循环、关小手 / 减少动态 / 拖动取消；接触点只平移手层的落点，不换图、不改节奏、不加手势动画。

实现以 [`store/skin-pack.js`](../../store/skin-pack.js) 和 [`packages/pet-core/src/data/skins.js`](../../packages/pet-core/src/data/skins.js) 为准；接触点的校验与落点换算见 [`packages/pet-core/src/core/skins.js`](../../packages/pet-core/src/core/skins.js)、[`src/client/skin-contact.js`](../../src/client/skin-contact.js) 和 [`src/client/pet-snap.js`](../../src/client/pet-snap.js)。
