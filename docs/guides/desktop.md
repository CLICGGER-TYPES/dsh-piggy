# 桌面版指南

桌面版不需要安装 DSH，玩法和插件版相同，但不会读取真实工作量。

## 安装

在 [GitHub Releases](https://github.com/CLICGGER-TYPES/dsh-piggy/releases/latest) 下载：

- Windows 安装版：运行 `dsh-piggy-setup-*.exe`。升级时可直接覆盖安装。
- Windows 便携版：运行 `dsh-piggy-portable-*.exe`。升级外壳时替换旧 EXE。
- Linux：给 AppImage 执行权限后运行；升级外壳时替换旧 AppImage。
- macOS：按芯片选 arm64 或 x64 DMG，拖入“应用程序”。未签名版本第一次需右键选择“打开”。

Linux GNOME 默认可能不显示托盘图标，可安装 AppIndicator 扩展，也可从主菜单点击“退出”。

## 拖动小猪

按住小猪即可在桌面上拖动，一直拖到屏幕边上都跟着鼠标走。面板是单独一个窗口（桌面外壳 0.6.0 起），贴在小猪上方或下方——哪边放得下就开在哪边；面板展开时也能拖，面板会跟着小猪移动，松开后按新位置重新选打开方向。开关面板、切 App、冒气泡都不会挪动小猪。点到桌面别处时面板自动收起（可在设置里关掉）。

每次启动时小猪停在上次的位置，面板是收起的，右键小猪打开。面板最高 520px，内容多时在面板里滚动。游戏里的 emoji 用内置的 Noto Color Emoji 显示，Windows 10 上也不会出现方框。

在主菜单「设置 → 小猪大小」可选小、标准、大、特大，按当前成长阶段原有大小的 ×0.85、×1、×1.3、×1.7 显示。换档时脚底中心留在原处；选择只存这台设备，不写进猪的存档。

## 存档与 DSH 导入

桌面版和 DSH 插件各自保存一只猪。桌面托盘菜单的“从 DSH 导入猪…”可以选择 DSH 的 `state.json`。导入、更新游戏包和覆盖安装桌面外壳都不会主动删除现有桌面存档。

## 更新

主菜单的“更新”App 会检查 GitHub Releases。有新版本时，主菜单显示红色感叹号，小猪也会提示一次。打开更新 App 后，本次提醒立即标为已读；即使暂时不安装，也不会一直显示。同一个版本不会反复冒泡，之后发布更新版本才会再次提醒。

更新 App 会分别显示游戏版本和桌面外壳版本。游戏包可以在 App 内下载、校验、备份存档并切换，也可以回退。外壳 v0.2.0 起，Windows 安装版和 Linux AppImage 可在 App 内下载新外壳并重启安装；Windows 便携版、未签名 macOS 版仍需到发布页下载替换。已安装的 v0.1.x 外壳需要手动升级一次，才能获得外壳自动更新能力。外壳 v0.3.0 起窗口相关的修复都跟着游戏包更新，外壳很少需要再升级。设置 → Emoji 样式可以在内置 Noto 和系统自带之间切换。详情见[更新机制](updates.md)。
