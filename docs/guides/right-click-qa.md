# 右键开面板的真实输入验收

只在独立临时存档、已孵化的小猪、没有其他任务同时输入的指定测试 VM 上跑。先核实窗口外坐标是安全空白，不能点击别人的程序或玩家存档。关闭“点别处自动收起”时不能用本流程，需先通过真实设置开关恢复默认。

1. 隔离启动未修复的 0.36.1，保留原始版本信息。在测试副本 renderer/index.html 的 loader 前加载 tools/qa-input-probe.js；它只观察真实事件，将事件类型、目标类名和坐标送入外壳已有日志，不改 DOM，不调用游戏动作。该脚本不会打进游戏包。
2. SSH 转发 CDP 端口。准备本机可执行的 `--log-reader`：只读本次实例的 piggy.log，标准输出返回 JSON `{ "text": "日志全文" }`。凭据从维护者提供的环境或凭据入口取得，不能写进仓库、输出或报告。
3. 用真实输入和整屏截图核实安全窗口外坐标，运行：

```sh
node tools/right-click-check.mjs --vm <测试VM> --cdp http://127.0.0.1:<转发端口> \
  --log-reader <本机只读日志程序> --outside <安全X>,<安全Y> \
  --shots <修前截图目录> --out <修前结果.json> --count 50
```

4. 六种条件轮换：常规待机、真实摸猪后动作仍在播、真实拖动后、面板刚关、从窗口外移回立即按、短间隔按下松开。每轮是从关闭状态开始的首次打开尝试；关闭走名牌取得焦点后点窗口外的真实路径，不计成额外右键。失败后的恢复右键独立记录，不能算首次成功。快速条件在首次打开已独立判定后再补四次真连按，期待关、开、关、开，补充事件单独记录且不混入首次成功数；补充结果也必须通过。
5. 每轮以外壳“panel shown”日志证明原生显示，并检查 200ms 后仍为打开。隐藏窗口的 DOM 属性不能单独证明窗口显示；本项目禁用了 backgroundThrottling，页面 visibilityState 也不可靠，见 [Electron 官方说明](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility)。
6. `latencyUpperBoundMs` 从按下真实右键开始算，到观察到原生显示日志为止，包含日志轮询与读取传输耗时，因此是上界。对比前后必须用同一日志读取器和采样方式。
7. 对照输入日志、原生显示日志和每轮截图，区分事件未进页面、进了页面未切换、切换后未显示、显示后立即关闭；还要确认没有其他任务抢走鼠标或焦点。过程需录屏或连拍，逐帧核对。
8. 找到机制、补能失败的回归测试，再修复；如果必须改外壳，先把已验证的根因、完整方案和升版要求写进任务结果，等维护者确认。修后同一条件再 50 次，要求首次成功 50/50，布局审计和整屏截图也要实际核对。

脚本准备就绪、静态取景校验通过，都不等于已完成这 50 次真实复现。中途任何准备失败、显示服务异常或未取得截图，都不能写完成标记。
