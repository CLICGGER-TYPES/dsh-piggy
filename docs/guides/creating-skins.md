# 制作自己的皮肤

[文档中心](../README.md) · [玩家换肤教程](skins.md) · [完整格式规范](skin-pack-format.md)

一套皮肤就是一个 ZIP 压缩包，里面放一个说明文件 `skin.json` 和若干张 SVG 图。下面按顺序一步步做：先看要画哪些图，再画、写说明、压缩、导入。

> 最省事的做法：下载[完整示例 ZIP](../examples/skin-pack-example.zip)，解压后逐张替换成你自己的图，改一下 `skin.json`，再按第 4 步压缩。示例的源文件也在[示例目录](../examples/skin-pack/)里。

游戏里也能随时查：打开 **🎨 换肤**，滑到最下面点 **「📐 怎么做皮肤：需要哪些图」**，会列出全部 11 张图、规格和 `skin.json` 的写法。

> 下方游戏界面截图拍摄于加入睡姿之前；游戏内最新列表和本页表格已包含 `sleep.svg`。

<p align="center"><img src="../screenshots/skins-guide/app-guide.png" width="360" alt="游戏里的「怎么做皮肤」页面（旧版截图）"></p>

## 第 1 步：看清要画哪 11 张图

猪在不同场景会换成不同的图。前 5 张**必须画**，后 6 张**可以不画**。缺少其他可选动作图时会用 `idle.svg`；缺少 `sleep.svg` 时会用默认小猪的睡姿，所以只画 5 张也能用。

<p align="center"><img src="../screenshots/skins-guide/poses.png" width="640" alt="旧版 10 个动作对照表（睡姿见下表）"></p>

| 文件名 | 必须？ | 什么时候出现 | 画什么 |
|---|:---:|---|---|
| `idle.svg` | 必须 | 平时待着；缺少其他可选动作图时也用它 | 站着、表情平静 |
| `eat.svg` | 必须 | 喂食 | 面前有食物、嘴在动 |
| `bathe.svg` | 必须 | 洗澡 | 澡盆、泡泡 |
| `play.svg` | 必须 | 玩耍 | 小球、开心的表情 |
| `pet.svg` | 必须 | 被摸摸 | 眯眼、冒爱心 |
| `relaxed.svg` | 可选 | 放松、番茄钟陪你专注 | 闭眼、安静 |
| `work.svg` | 可选 | 打工 | 桌子、电脑、工具 |
| `study.svg` | 可选 | 上学 | 书本 |
| `trip.svg` | 可选 | 旅行 | 背包、行李 |
| `fish.svg` | 可选 | 钓鱼 | 鱼竿 |
| `sleep.svg` | 可选 | 打盹 | 横躺或蜷着睡，脸和衣服保持这套皮肤的样子；可画睡垫 |

内置小猪的睡姿效果可参考[这张图片](../../assets/piglet-sleep.png)。自制皮肤仍须提交符合下文规格的 `sleep.svg`，不能把 PNG 放进 ZIP。

文件名必须**完全一样**（全小写英文、`.svg` 结尾），写错或用了大写都会被当成多余文件拒绝。

## 第 2 步：画图（64 × 64、脚底对齐）

<p align="center"><img src="../screenshots/skins-guide/align.png" width="640" alt="64×64 画布、身体居中、脚底贴在同一条线上"></p>

- **画布**：每张图的 SVG 根元素都写 `viewBox="0 0 64 64"`。
- **透明背景**：不要铺一整块白底，否则桌面上会出现一个白方块。
- **对齐**：猪的身体左右居中，**脚底在每张图里都贴着同一条线**。最简单的办法是拿 [`assets/piglet.svg`](../../assets/piglet.svg)（默认小猪）当底稿，在上面描或改。不对齐的话，切换动作时猪会上下跳一下。
- **睡姿单独画**：`sleep.svg` 仍用 64 × 64 透明画布，让横躺的猪和睡垫留在画布内，视觉中心与站姿一致。睡姿不用按站姿对齐脚底；图里需要完整画出衣服和配饰，打盹时站姿装扮会隐藏。
- **道具可以画在身体旁边**：食物、澡盆、鱼竿等都行，但别超出 64 × 64，超出的部分会被切掉。
- **只用简单图形**：路径、圆、矩形、多边形，纯色填充和描边都可以。下面这些会被拒绝：
  - 位图（`<image>`）和任何外链（`href`、`src`、`url(...)`）；
  - 文字（`<text>`）——要写字先在编辑器里「转换为路径」；
  - 脚本和事件属性（`onclick` 等）；
  - 渐变、滤镜（阴影、模糊）；
  - `<style>` 样式表和 `<use>` 引用——颜色直接写在图形的 `fill`、`stroke` 属性上。
- **大小**：单张图不超过 96 KB。

导出时的小提示：

- **Inkscape**：先把文字「转换为路径」（Shift+Ctrl+C），再「另存为 → 优化的 SVG」。
- **Illustrator**：「导出为 → SVG」，样式选「演示文稿属性」（不要选「内部 CSS」），字体选「转换为轮廓」。
- **Figma**：把文字 Outline 后，选中画框「Export → SVG」。

导出后用文本编辑器打开看一眼：开头是 `<svg ... viewBox="0 0 64 64">`，里面没有 `<style>`、`<text>`、`<image>`、`Gradient` 就对了。

## 第 3 步：写 skin.json

在图片旁边新建一个文本文件，命名为 `skin.json`（注意扩展名不能是 `.txt`）：

```json
{
  "key": "my-blue-pig",
  "label": "蓝莓猪",
  "author": "你的名字",
  "description": "关于这套皮肤的一句话。",
  "emoji": "🫐"
}
```

| 字段 | 必须？ | 说明 |
|---|:---:|---|
| `key` | 必须 | 皮肤的编号。只能用小写字母、数字、短横线，最长 24 位，不能和内置皮肤（如 `mint`、`detective`）重名。以后发新版本**保持同一个 key**，玩家再导入就会覆盖旧版 |
| `label` | 必须 | 玩家看到的名字 |
| `author` | 可选 | 作者，不写显示「玩家」 |
| `description` | 可选 | 换肤列表里的一句话介绍 |
| `emoji` | 可选 | 名字前面的小图标 |

最后一项后面不要加逗号，否则会提示「skin.json 不是有效 JSON」。

## 第 4 步：压缩成 ZIP（最容易出错的一步）

打开 ZIP 必须**直接看到** `skin.json` 和 SVG，不能多包一层文件夹，也不能有别的文件：

<p align="center"><img src="../screenshots/skins-guide/zip.png" width="640" alt="左：正确的 ZIP 结构；右：多包了一层文件夹会报错"></p>

正确的做法是**进入**皮肤文件夹，选中里面的文件再压缩，而不是对着整个文件夹压缩：

- **Windows**：进入文件夹 → 选中 `skin.json` 和所有 SVG → 右键「压缩为 ZIP 文件」（Windows 10 是「发送到 → 压缩(zipped)文件夹」）。
- **macOS**：进入文件夹 → 选中这些文件 → 按住 Control 点击 →「压缩」。如果导入时提示「ZIP 只能在根目录放…」，多半是访达顺带塞进了 `__MACOSX` 隐藏文件，改用下面「终端」的命令压缩。
- **Linux / macOS 终端**：在皮肤文件夹里运行

  ```sh
  zip -j -X my-skin.zip skin.json *.svg
  ```

  `-j` 去掉路径，保证文件都在 ZIP 根目录；`-X` 不写入多余的系统信息。

不要给 ZIP 设密码。整个 ZIP 不超过 2 MB。

## 第 5 步：导入并检查

1. 打开猪猪面板 → **🎨 换肤**，滑到最下面「导入自己的皮肤」。
2. 点 **「选择 ZIP」**，选刚才的压缩包。
3. 成功时猪会说「皮肤导入成功 🎨」，新皮肤立刻换上，列表里也会出现它。

<p align="center"><img src="../screenshots/skins-guide/app-import-ok.png" width="360" alt="导入成功：猪说「皮肤导入成功」并换上新皮肤"></p>

导入时会先把整个包检查一遍，只要有一项不合格就**什么都不写入**，猪会说出问题在哪。比如多包了一层文件夹：

<p align="center"><img src="../screenshots/skins-guide/app-import-error.png" width="360" alt="导入失败：ZIP 只能在根目录放 skin.json 和 SVG"></p>

导入后逐个场景看一遍：喂食、洗澡、玩耍、摸摸，以及你画了的可选场景。打盹时检查睡姿和头顶偶尔出现的 `Zzz` 气泡。重点看动作切换时猪有没有上下跳（脚底没对齐）、道具有没有被切掉（超出了 64 × 64）。

网页版（DSH 里）和桌面版的导入入口、提示完全一样。

## 报错对照表

| 猪说的话 | 原因 | 怎么改 |
|---|---|---|
| ZIP 只能在根目录放 skin.json 和 SVG | 多包了一层文件夹；ZIP 里有别的文件（`.png`、`.DS_Store`、`__MACOSX` 等）；文件名有大写；ZIP 设了密码 | 按第 4 步重新压缩，只选 `skin.json` 和 SVG |
| 缺少 idle.svg（或其他） | 必须的 5 张没齐，或者文件名拼错 | 对照第 1 步的表补齐、改名 |
| xxx.svg 必须使用 viewBox="0 0 64 64" | 画布不是 64 × 64 | 在编辑器里把画布改成 64 × 64 再导出 |
| xxx.svg 含有不允许的外链、文字、脚本或滤镜 | 图里有文字、位图、渐变、阴影、`<style>` 等 | 按第 2 步：文字转路径、颜色写在属性上、去掉渐变和滤镜 |
| xxx.svg 太大或压缩方式不支持 | 单张超过 96 KB，或用了特殊的压缩算法 | 简化路径；用系统自带的压缩 |
| skin.json 不是有效 JSON | 引号、逗号写错，或者文件其实是 `skin.json.txt` | 对照第 3 步的示例检查 |
| key 只能用小写字母、数字和短横线，最长 24 位 | `key` 写了大写、中文、空格 | 改成类似 `my-blue-pig` |
| key 与内置皮肤重名 | 用了 `mint`、`detective` 等内置名字 | 换一个自己的 key |
| 缺少皮肤名称 label | `skin.json` 没写 `label` | 补上 |
| ZIP 不能超过 2 MB | 整个包太大 | 简化 SVG，删掉编辑器留下的元数据 |
| 这不是 ZIP 文件 / ZIP 文件损坏 | 选错了文件，或者压缩包不完整 | 重新压缩一次再导入 |

更详细的字段和限制见[完整格式规范](skin-pack-format.md)。
