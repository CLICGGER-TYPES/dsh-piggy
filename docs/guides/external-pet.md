# 外部桌宠模式（未发布候选）

默认仍然分别养 DSH 内嵌猪和桌面猪。这个功能是可选连接，不会自动合并两份存档。

桌面版设置里的「外部连接 → 允许本机的 DSH 联动」默认关闭。打开后，桌面在本机启动独立的配对接口和工作接口。DSH 设置里的「外部桌宠」可重新检测并连接；浏览器不会收到接口令牌。

「只把工作和面板交给桌面猪」会暂停内嵌猪，暂存期间不饿、不病、不长大。DSH 面板操作转给桌面猪，工作事件只投递一次到桌面目标。桌面断开时保留外部模式与工作队列，不自动回退成另一只猪。切回内嵌后，从暂存时间接着养。

「把内嵌猪合并到桌面猪」先检查两边活动，再给出完整预览。金币和物品相加，解锁合并，进度按批准的字段规则处理；名字、样子、性格与偏好可以逐组选择。无法自动合并的扩展逐个二选一；疑似同一份存档也需要明确选择。预览取消时恢复原状态。

提交后还需要在桌面原生确认框中允许合并，60 秒不响应按拒绝处理。请求链路留出这段等待时间；结果未知时只查询原事务状态，不再次相加。两边分别备份后才提交，内嵌猪成功退役后停止生长。最近一次合并可撤销，恢复两份存档，且先备份合并后的桌面进度。

实现边界：

- 配对和工作接口只监听 `127.0.0.1`，令牌独立，拒绝跨站来源；这不是公网/跨设备连接功能。
- 桌面 split 和 stage 共用联动管理器；只有主游戏窗口能打开许可，扩展窗口不能操作此设置。
- DSH 管理路由始终存在，面板路由随内嵌/外部模式互斥切换，避免两套存档同时接收操作。
- 在线扩展合并只调用桌面已安装且声明支持的钩子。异常、非法数据或未解决冲突降级为二选一。
- 普通手动备份不受最近一次合并备份清理影响。
