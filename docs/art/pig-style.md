## 统一风格

- 用户已确认猪相关游戏素材统一为透明 PNG：基础猪、形态、皮肤、睡姿、反馈图及动画帧。现有 SVG 逐批重生成，经审图后迁移；不自动描摹或把 PNG 包进 SVG。界面中无关的矢量图标不属于这次猪素材迁移。
- 同一只基础猪：桃粉色身体、粉色扁椭圆鼻子、两枚鼻孔、深色小眼睛、圆软小耳朵、短腿、卷尾。保持原有可爱神态、胖瘦与姿态识别；皮肤围绕同一基础角色变化。
- 完整猪身、耳朵、尾巴、腿、服饰和主要道具都有干净黑色轮廓线，圆润接头；内部结构线轻一些。线围着形体走，不是矩形画框，不加白色贴纸边。线宽以用户通过的样图为基准，再随成品尺寸等比例缩放。
- 简洁二维 Q 版、柔和配色、平涂或非常轻的暖色层次。避免写实毛发、复杂材质、高光球体和立体玩具质感。
- 姿势与动作语义逐图保留：躺平、去世、寻访、玩梗与黑色幽默不得为了“可爱”而被改成另一件事。身份道具不能凭空增加或丢掉。
- 用统一可见高度与视觉中心校准。透明留白不能让换皮肤明显变大变小；帽子、翅膀、尾巴和脚保留安全边距。侧面或三分之四视角的闲置图保持朝左，动作图按既有构图。
- 天使的翅膀明显大而完整，从背部自然连出；近远翅膀有遮挡次序。厨师服、帽子等贴合身体，衣领、衣摆和腿位置对得上。

## 生成与自查

1. 用 `image_gen` 生图，提供当前角色和已通过同系列图片；先保存逐字提示词、参考文件、工具名与版本号。不能把复用摘要冒充原始提示词。
2. 每个角色或动作单独一张，版本递增；保持整只猪构图，避免多角色拼图导致身份和肢体混淆。
3. 全尺寸检查肢体数量、鼻孔、耳朵、尾巴、衣服接缝和道具遮挡；四脚站姿不能出现第五条腿，动作中被遮挡的腿无需强行露出。
4. 检查透明背景、白色衣服和眼白、封闭区域、尾巴孔和腿间空隙。不要运行时抠白；原生透明图保留 alpha，需抠底时从原尺寸图离线处理。
5. 深浅背景图只是检查透明边缘的自查预览，不能充当游戏素材；默认给用户一张总览和透明原图链接，不重复发送两套背景图。检查黑线是否连续、边缘是否有白边、头顶和脚是否裁切；在深浅背景及游戏尺寸预览后记录实际问题。发现缺陷用生图工具重修，不把缺陷当作“已通过”。
6. 自查通过的仍是“待用户审图”，只有用户确认才进入 approved，再生成游戏导出图。原尺寸图留素材工作区，游戏图长边不超过 256px，记录 PROVENANCE 和角色/动作映射。

## 同一动作的跨皮肤一致性

用户指出第七批洗澡姿势和肢体不统一。相同体型的皮肤必须引用同一个动作母图，只替换皮肤身份细节，不各自重新解释姿势。用户随后指出坐姿头部结构有问题，旧坐姿基准停用。新洗澡待审基准为普通猪 piglet-bathe-v3：低身横趴浴盆，两只短前蹄并排搭前盆沿，后腿被浴盆完全遮挡；耳朵后不得有额外皮肤圆包或深颈凹口，额头到臀部是一条饱满、向外凸出的圆弧；不得用S形下降曲线连接，不得凹背。统一水位、鼻眼位置和浴盆尺寸，不得有的趴、有的坐、有的抱泡沫。脱衣洗澡的普通体型皮肤，仅旁边凳上的身份物品不同。胖猪、圆猪等不同体型保留各自形体，仍采用同一动作关系。母图经用户通过后供后续复用。
