# 小游戏美术默认风格：清爽平涂纸感

2026-10-24 用户选定菜园 A 方案后明确要求：后续有些小游戏需要出图，默认沿用这种风格。新小游戏及后续需要补画的场景、地块、物件优先按此执行；已有美术不因此自动批量替换。

视觉基准：[用户确认的菜园 A 样稿](game-paper-reference.png)。这是风格参考，界面文字、布局、玩法和数值仍以各功能获批方案为准。

- 低密度、留白充分，主体和可交互目标容易辨认，不堆建筑、围栏和装饰。
- 采用清楚的平面色块和轻纸张质感，柔和草绿、奶油色、暖土色；色彩按场景需要变化，保持同样轻巧的层次。
- 不用纯黑重描边、写实高光、厚重立体造型或浓雾光晕。以轮廓和明度区分材质与前后关系。
- 场景背景、地块、物件、生长阶段分别出图；文字、按钮、进度、目标提示由界面独立绘制，不烘焙进插画。
- 原生 AI 出图，保留逐字提示词、参考图、生成源和哈希；透明图使用真实透明底。导出只按用途等比例缩放，实际合成效果在虚拟机内验收。
- 小猪本体遵守 [pig-style.md](pig-style.md)，不借场景换风格改变耳朵、鼻子、四肢或服饰结构。

已有 29 种普通作物暂保留真实种类和阶段图片。本轮新背景与首课小葱按 A 制作；没有把全部旧作物宣称为已重画。
