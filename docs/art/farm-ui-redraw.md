# 菜园界面整体重画验收（未发布）

本地分支 `farm-ui-redraw` 从 `aedb7a4` 创建。游戏 0.37.1、菜园 4.0.8 / minGame 0.37.1、桌面外壳 0.6.6。大农场采用用户选定 B，小农场生成三种 292×520 方案，自主选 C1 连续羊皮纸：与 B 一致，花叶/浅木纹只作点缀，场景和工具更清楚。用户晚间授权取消中间等待；没有推送、合入 0.37 或发布。

## 实现与素材

原生 DOM/CSS 实现暖羊皮纸、薄荷立体按钮、燕尾标题、有机弹框、页签、卡片、徽章与进度。花叶、木纹、关闭/加/减/锁定共 7 张透明 WebP，40,520 字节，长边 ≤256px；透明 PNG 审稿源保存在素材工作区。全部声明素材 263 张 / 4,229,070 字节；旧图保留。来源与逐图哈希见 [PROVENANCE](../../extensions/farm/PROVENANCE.md)、[素材表](../../extensions/farm/redraw-art-pack.json)。

背景、作物、猪与养成规则沿用；取消小地块重复叠放的作物副本。小面板按宿主标题和实际剩余高度分配场景，5 工具与底部 3 操作完整，短面板可以滚动。名称统一种子袋/帮工仓库。正文使用既有系统字体回退，不增加字体格式或联网字体。

图片张数、图片总大小、整包/导入请求按 4MB 推算的上限已移除；文件名/类型、重复文件、单文件 512KB 和 SHA-256 检查保留。300 张×32KB（9.375MiB）图片通过文件集合、整包、本地 HTTP 导入和打包验证；旧实现被新用例抓到数量上限。旧游戏拒绝 minGame 0.37.1 的新菜园。

## 验证

- `npm run build`：单文件 client.js 569,400 字节，与源码构建一致。
- `npm test`：1077 项通过；`npm run typecheck` 通过。
- 布局审计：七组合（1280×800、1092×691、720×480 大窗口；292×520、292×120 小面板各顶部/底部），16 常规状态及 29 作物×6 阶段，共 1322 组合，0 违规、0 页面错误/资源失败。改前同方法 104 常规组合，0 违规/错误；本轮解决的是外观，不能把原有审计通过说成原版无视觉问题。
- 审计支持真实圆角可点范围、有机 CSS 弹框和标题丝带伪元素；新增真实遮挡与文字溢出的失败用例，原阈值保留。
- Browser 插件没有可调用的托管浏览器运行工具，因此使用临时 Playwright / 系统 Chromium 测矩阵；桌面鼠标通过 GNOME Mutter RemoteDesktop 原生输入，CDP 只读取坐标/审计，不派发点击。

Linux VM `ubuntu26.04-2` 使用隔离源码与存档，Electron 44.5.1 / 外壳 0.6.6。逐张截图查看大农场、商店四页签、购买、悬停、铲除确认、种子袋、仓库、帮工搬运、小农场。原生鼠标动作及后台读数：

| 操作 | 前 | 后 |
|---|---|---|
| 买白萝卜种子 3 包 | 菜币 12800，种子 24 | 菜币 12560，种子 27 |
| 取消铲除 | 地块为白萝卜 | 仍为白萝卜 |

最终桌面大窗口 1092×691、小窗口 303×520（包含超出卡片的猪名称 HUD，卡片实际宽 292px），两者布局审计均 0 违规。截图保留实际窗口几何，不把 303px 窗口缩成 292px 冒充实际尺寸。第一张失败截图已归档 rejected：宿主标题挤占高度时底栏裁切，已按实际剩余高度修复；最终图见素材工作区 review/farm-ui-redraw-vm。

没有 Windows/macOS 实机验证。VM 图形环境记录了 VA-API/GPU 初始化提示和远端更新 SSL 握手失败；本地菜园绘制及购买/仓库操作正常，这些环境日志不算作已解决。本轮无待跳过的要求项。测试结束清理本轮进程、测试存档及临时访问授权，并将原先关机的 VM 恢复关机。
