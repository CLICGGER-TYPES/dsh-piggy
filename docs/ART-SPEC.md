# 🐖 美术需求单 · 完整版

**目标**：把现在用 emoji 表示的一切，换成手绘 SVG。

> 2026-10-09 起也可以**直接用 AI 出图**（agent 自带的生图工具即可），交透明底 PNG，不必描成 SVG。
> 规格和许可见 [新功能指南](guides/adding-features.md) 3.5「图可以直接用 AI 出」。下面的 SVG 约束只在交 SVG 时适用；配色、朝向等风格规则两种都要遵守。
**每一项都对应代码里真实存在的状态**（文件、尺寸、触发条件都是从源码里对出来的）。

## 零、硬性技术约束

| | |
|---|---|
| 格式 | `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" width="64" height="64">` |
| 图形 | 只用 `<path>` `<ellipse>` `<circle>` `<rect>` `<polygon>`。**不要** `<image>` `<text>` 渐变 滤镜 |
| 背景 | **透明**。不要矩形底、不要地面、不要投影 |
| 画布 | 图形占视框 ~90%，四周留 2-3 单位，视觉居中 |
| 描边 | **零描边**（除了耳朵/尾巴/眉毛那种「圆头线条」，用 `stroke` + `stroke-linecap="round"`） |

### 风格锁定（以 `assets/piglet.svg`、`assets/elder.svg` 为准）

| 部位 | 颜色 |
|---|---|
| 身体 / 近侧腿 | `#FFD1AF` |
| 远侧腿 | `#FF9FA5` |
| 鼻子 | `#FF8195` |
| 耳朵（圆头弧线） | `#E95892` |
| 眼睛 | `#373A32` |
| 腮红 | `#FFAFAC` |
| 尾巴 | `#FFD1AF` |

**老年猪配色**：身体 `#F1C09D` · 耳朵 `#CF6C89` · 鼻子 `#ED8B98` ·
灰眉毛 `#ADADA5` · 皱纹 `#CA997E` · 白胡子 `#F8F4E8`

**四条不可违反的规则**
1. **侧面朝左**（和现在的 🐖 一致）
2. **平涂，零描边**
3. **眼睛是不规则的形状**，不是正圆
4. **耳朵是圆头弧线**，不是填充三角

| ☐ | 文件 | 尺寸 | 画什么 | 动画 |

## 九、动画怎么来的（画图的人只需知道这个）

**大部分不需要逐帧。** 动画是 CSS 变换作用在**单张静态图**上：

| 效果 | 实现 | 用在哪 |
|---|---|---|
| 呼吸 | 1.8s 上下浮动 | 默认 |
| 打字 | 0.7s 小幅抖动 | 打工 |
| 看书 | 2.4s 慢速歪头 | 上课 |
| 走路 | 1s 弹跳 + 摇摆 | 旅行 |
| 咳嗽 | 0.35s 急促抖动 | 疾病 |
| 长大 | 缩放 + 星星粒子 | 阶段变化 |
| 睡着 | 2.6s 缓慢呼吸 | 睡觉 |
| 心形升起 | 独立 emoji 粒子 | 摸摸 |

所以**一张静态图 = 一个完整动画**。只有第四节那三个外出场景，
你要是想要真正的逐帧序列，才需要额外画。

## 十、给你的自查表（每张画完自己过一遍）

对着每张新图检查，**这五项是最容易翻车的**：

| 检查 | 怎么看 |
|---|---|
| ☐ **侧面朝左？** | 鼻子在左边。鼻子画到右边就是反的 |
| ☐ **零描边？** | 放大到 400%。身上不该有深色轮廓线 |
| ☐ **眼睛不规则？** | 不该是一个完美的圆。参考 `piglet.svg` 的眼睛 |
| ☐ **耳朵是弧线？** | 洋红色圆头**线条**，不是填充的三角形 |
| ☐ **和现有两张并排不违和？** | 把新图、`piglet.svg`、`elder.svg`、🐖 四个放一排看 |

**最后一项最重要。** 只要有违和感，就是配色或者比例跑偏了。

### 并排检查的命令

```sh
cd <仓库根目录>
xdg-open tools/style-check.html
```
