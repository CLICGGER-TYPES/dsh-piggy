# X2 · 扭蛋（数值单）

> 2026-10-05 · 用户：「快点看了 github 然后设计数值单去搞」——按这份先做，用户试玩后再调。
> 定位：便宜、出**现有的消耗品**（食物、洗浴、玩具、药、鱼饵），不出摆件和装扮（那是盲盒的）。期望价值约等于价钱的八成，靠金色胶囊的大奖和幸运值保底让人想扭。

## 1. 价钱和次数

| | 值 |
|---|---|
| 扭 1 次 | 60 🪙 |
| 扭 10 次 | 540 🪙（九折） |
| 每天免费 | 第一次免费（06:00 换天） |

## 2. 胶囊颜色（三台口味都一样）

| 胶囊 | 概率 | 一颗里有什么 |
|---|---|---|
| ⚪ 白（普通） | 80% | 从普通池抽 1 样，**×3** |
| 🔵 蓝（稀有） | 17% | 从稀有池抽 1 样，**×2** |
| 🟡 金（超稀有） | 3% | 从大奖池抽 1 样，×1 |

- **幸运值**：每扭一次 +1，到 20 时下一次必出金色，出金色（不管是不是保底出的）清零。
- 十连里每一颗单独算，幸运值照常累加。
