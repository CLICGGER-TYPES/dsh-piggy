## 先说清楚的几条规则

| | 建议 | 你的决定 |
|---|---|---|
| 一次操作冒两句话 | 去掉客户端那句固定的（「出门打工！」「买到了！」等），只留核心那句；特效照常 | |
| 同一句不连着说 | 每个场景记住最近 3 句，不重复（现在只记 1 句） | |
| 按时间说话多久一次 | 同一个时段只说一次（比如早上那句一天一次）；喝水提醒在线满 90 分钟一次，休息眼睛满 2 小时一次；免打扰开着都不说 | |
| 摸太多会不耐烦 | 30 秒内摸到第 8 下开始不耐烦，再摸心情不再加；停 1 分钟恢复 | |
| 猪自己找事做多久一次 | 面板收着、猪在家闲着时，每 3～8 分钟做一个小动作，持续 3～6 秒 | |
| 桌面散步 | 设置里一个开关，**默认关**。开了以后每 10～20 分钟沿屏幕底边走一段（不超过 300 像素）再走回原位；你拖它、开着面板、免打扰时都不走 | |
