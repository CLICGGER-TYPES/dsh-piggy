## 3. 宠物日记

| 项 | 建议 | 你的决定 |
|---|---|---|
| 多久一篇 | 每天一篇，06:00 之后第一次结算时，把**前一天**写成日记 | |
| 谁写 | **先用模板拼**（零 token，符合插件「不花 token」的原则）；以后想接 DeepSeek 再单独加开关 | |
| 保存几篇 | 最近 **60 篇**，更早的删掉 | |
| 放在哪看 | 背包页加一个「📔 日记」分栏（不加第 7 个图标，面板只有 292px 宽） | |
| 前一天什么都没发生 | 也写一篇短的：「今天[主人]没来，我睡了一整天。」 | |

**写什么**（从前一天的记录里挑，最多 5 句，用猪的口吻）：

- 吃了什么、洗了几次澡、被摸了几次
- 打了什么工、赚了多少；上了什么课、有没有毕业
- 去哪旅行、带回了什么
- 生病、吃错药、病好
- 升级、长大（换形态）
- 陪[主人]干了多少活（真实对话轮数、工具调用次数 —— 这是 DSH 版独有的）

示例：

> 9 月 30 日　晴
> 今天吃了 2 个苹果和一碗拉面，好饱。下午去搬砖，赚了 120 金币！
> 数学课上到第 9 节，我小学毕业啦，没有留级。
> [主人]今天敲了 43 轮代码，我在旁边看着，也长大了一点。
