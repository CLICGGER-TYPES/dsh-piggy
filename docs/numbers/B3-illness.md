## 3. 怎么得病（从「必病」改成「概率」）

在家时每小时掷一次骰子，概率叠加：

| 条件 | 每小时发病概率 | 得哪条链 |
|---|---|---|
| 基础（照顾得再好也有） | **0.2%**（平均约 3 周一次小病） | 随机 |
| 饿（饱食 < 25%） | ~~+8%~~ **+3%** | 感冒 |
| 脏（清洁 < 35%） | ~~+8%~~ **+3%** | 咳嗽；清洁 < 15% 时改为皮肤 |
| 心情差（< 30%） | **+5%** | 头晕 |
| 连续打工/上课 ≥ 3 次没休息 | **+5%** | 头晕 |
| 吃撑（饱食已经 ≥ 95% 还喂） | 每次喂 **25%** 立刻得 | 肠胃 |

- 例：又饿又脏，每小时约 6%，**一半的猪 11 小时左右会病**（B3 以前是 12 分钟必病）
- 在外面（打工/上课/旅行）时不会得新病（保持现状）
- 已经生病时不会再得第二种病（保持现状）
