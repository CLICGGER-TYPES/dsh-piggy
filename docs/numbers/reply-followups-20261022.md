## 接入行为

1. 一轮为「猪说话 → 玩家选回复 → 猪接一句」。接话不继续附回复按钮，不自动无限追问。
2. 接话准确关联原句和所选按钮；优先使用当前性格对应句，换性格后不适用或未知性格时，使用该分支的通用句。
3. 只在服务端确认回复有效后展示；同一条回复只加一次原有心情，不加金币、不追加摸摸次数、不消耗物品，不自动执行喂饭、洗澡或吃药。台词里的日常动作是说话表现，不替代实际操作。
4. 主人回复算主动互动，应唤醒真正睡着或正在打盹的猪；不额外插入「被吵醒」台词来覆盖接话。
5. 回复提交遇到前一操作繁忙时不能悄悄丢弃；失效回复不能被伪造成有效，也不能重复奖励。失败保持可判断的显示状态。
6. 猪窗口和面板共享同一次服务端结果，按消息ID去重；同次奖励不能抹掉接话。急病、死亡等真实状态保留优先级。
7. 接入时使用稳定的原句身份，不依赖临时显示文字、口头禅或主人称呼猜测。若增加存档对话字段，必须同时做版本迁移与旧存档测试；不能清空用户资料或用重置存档代替兼容。
