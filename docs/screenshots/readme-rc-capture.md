# README 截图来源

这组三张图是在隔离的 DSH 本地网页中，通过 Playwright 操作候选程序的实际界面后直接截取。没有合成、修图或改动界面比例。

- 游戏包：`dsh-piggy 0.37.1-rc.1`
- 菜园扩展：`4.0.9`，由本候选目录生成 `.piggyext`，再从设置页通过文件导入
- 桌面外壳候选版本：`0.6.7-rc.1`（网页截图未运行桌面外壳）
- DSH：本机 `deepseek-harness` 工作树；临时插件配置指向本候选目录
- 浏览器：预装 Chromium 153 + Python Playwright；宿主 Browser 控制接口不可用
- 浏览器视口：1440 × 1000 CSS px，device scale factor 2；主页和小农场使用界面元素截图，大农场使用全窗口元素截图
- 存档与浏览器资料：新建的临时 `DSH_HOME`、state 文件和 Chromium profile；所有临时数据及进程在结束时清理

正常 UI 操作路径：关闭 DSH 首次运行提示并选择稍后配置；在小猪面板打开主菜单；从「设置 → 扩展」导入菜园 4.0.9；从主菜单第二页打开菜园；通过钱包 UI 将 100 金币换为菜币；分别截取小农场和「大农场」。
