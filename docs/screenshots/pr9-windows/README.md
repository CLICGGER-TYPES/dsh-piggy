# PR #9 Windows 桌面验收

2026-10-09 在 Win11 虚拟机的原生 Electron 桌面外壳 0.6.0 中，以本 PR 的游戏包运行。屏幕为 1280×800 像素、125% 缩放。存档使用隔离的测试目录；深色壁纸为 `#263347`，浅色壁纸为 `#ecebdc`。

`dark-*.png` 和 `light-*.png` 是七种状态的完整桌面截图：`box` 猪递、`sick` 生病、`dirty` 脏、`dead` 去世当天、`ghost` 墓碑旁幽灵、`work` 打工、`happy` 开心。`contact.png` 是这 14 张图的局部拼图，便于查看图像边缘。检查结果：14 张都没有矩形白底或可见白边；图中的白衣服、眼白和高光保留。

`first-right-click.mp4` 是原生桌面录屏：指针从桌面空白处连续移到猪身上，右键一次，面板随即打开。录屏开始约 3.35 秒按下右键，约 4.95 秒画面显示面板。这个首次打开包含面板窗口加载时间；没有第二次右键。瞬移指针的自动化尝试会落到 Windows 桌面菜单上，不能代表连续的真实鼠标移动，因此验收采用连续轨迹。
