# 桌面网络代理

用户已授权设置面板增加代理选项并调整控件布局。位置：设置的桌面散步之后、日志之前。

## 使用方式

- 跟随系统：使用操作系统的代理配置，默认选择。
- 直连：仅小猪绕过系统代理。
- HTTP / SOCKS5：填写 `主机:端口`，也接受对应协议前缀，再点“应用”。支持 IPv6 地址，例如 `[::1]:1080`。不接收带账号密码、路径或多条路由规则的地址。
- 测试已应用配置：访问当前发行渠道的扩展目录，显示成功或具体错误以及 Electron 解析出的代理路线。未应用的输入不会影响测试结果。
- 清除配置：删除小猪的 `userData/proxy.json` 并恢复跟随系统；不修改操作系统代理。

配置独立于小猪存档，重启后保留。应用前校验地址；任一网络会话应用或配置保存失败时恢复原配置。损坏的配置文件不阻止启动，面板提示重新应用或清除。

## 网络接入

代理配置和桌面消息广播需要更新外壳；仅更新游戏包不能提供这两项外壳能力，旧外壳不会显示代理入口。

在首次游戏下载之前初始化代理，覆盖默认 Electron 会话和 `electron-updater` 的独立会话。游戏更新使用 `net.fetch`；桌面宿主把同一个 fetch 注入在线扩展运行时。网页版仍使用原有宿主网络方式。

改变代理时关闭旧连接，防止连接池复用原代理；正在下载的请求可能因此中断，需要重新发起。外部浏览器打开发布页时使用浏览器自己的配置。

参考：[Electron ProxyConfig](https://www.electronjs.org/docs/latest/api/structures/proxy-config)、[Electron session](https://www.electronjs.org/docs/latest/api/session)。外壳更新的独立会话以当前安装的 `electron-updater/out/electronHttpExecutor.js` 为依据。

## 已执行验收

本地原生 Electron：系统代理、HTTP、SOCKS5 都成功读取实际在线目录；HTTP 显示 `PROXY` 路线，SOCKS5 显示 `SOCKS5` 路线。清除后恢复系统模式。调试台词连续 10 个场景均显示气泡；散步按钮在面板窗口可点击并驱动猪窗口。构建、类型检查和 753 项测试通过。地址输入跨一次 4 秒状态轮询不丢失。在线扩展实际接口返回 6 个条目、无错误。

自动测试覆盖端点校验、持久化、两个会话配置一致、失败回滚与清除。Windows / Ubuntu 虚拟机尚未执行本轮验收；安装版外壳的实际更新下载尚未执行。
