# 小猪表情叠层与徽章高光演出（预留设计）

日期：2026-11-05
状态：**仅预留思路，不实现**；静态素材清理先做。

## 背景

当前猪图和徽章里的腮红、鼻旁白点都是烘焙进 PNG 的静态像素：

- 默认幼年猪已经去掉 `idle` / `blink` / `shy-pet` 的单侧腮红；
- 徽章里的鼻旁白点是 AI 出图带出来的高光点，已去掉 6 张，仍有 27 张；
- 其余皮肤/形态/反馈图里的单侧腮红约 148 张。

这些像素如果继续烘焙在图片里，会出现三个问题：

1. 同一只猪的 `idle` 没腮红，洗澡/吃饭时腮红又回来，静态图不一致；
2. 想按心情做“害羞脸红”“开心脸红”时，只能换整张图；
3. 白点这种生成瑕疵要么删掉，要么只能一直留在图上。

## 目标

把“腮红 / 鼻旁高光”从**静态图**改成**运行时可开关的叠层**：

- 静态 PNG 只保留干净的脸；
- 客户端按状态叠加腮红、星星、闪光；
- 同一套叠层可以渐入渐出、呼吸、跟随动作；
- 不重画整张猪图，不改变存档和玩法。

## 非目标

- 本轮不改代码、不改素材、不发版。
- 不新增猪的骨骼/整身动画系统；只做脸部和徽章的小叠层。
- 不用叠层掩盖真实问题（比如缺图、错图）；缺图仍然走现有回退。

## 方案 A：运行时腮红叠层

### 表现

- 默认隐藏；触发时在左右脸颊渐入一块柔边腮红。
- 害羞/被摸：0.18–0.25 秒渐入，停留 0.8–1.2 秒，再渐出。
- 开心/升级/生日：短暂加强，可带一次轻微脉冲。
- 生病/发烧：用独立色（偏红/偏灰），不与普通腮红共用颜色。
- 睡眠：可选双侧淡腮红，默认关闭。

### 挂点

不把位置写死在代码里，复用现有取景数据：

- `src/client/feedback-framing.js` 已有每张猪图的取景/边界；
- 新增可选的 `expression` 元数据：左右脸颊锚点、半径、旋转角；
- 没有元数据的图，用默认相对位置（按当前 256×256 画布的脸部比例）；
- 自定义皮肤包可选带 `expression` 字段，缺省走默认锚点。

### 渲染

- 在猪图上方叠一个绝对定位的 `<canvas>` 或 `<div>`，大小跟随猪图；
- 只用 `opacity` / `transform` / `filter`，不触发布局；
- 用现有 Motion 依赖做弹簧/缓动，不新增运行时库；
- 猪图切换、皮肤切换、隐藏、卸载时立即清理叠层；
- 不改变 hit area，不拦截鼠标事件。

### 触发

- `pet`：害羞腮红；
- `feed` / `play`：开心腮红；
- `levelup` / `birthday`：加强版 + 可选星星；
- `mood`：长期低强度腮红（可关闭）；
- 设置页提供“表情叠层”开关；`prefers-reduced-motion` 时只保留静态淡色，不播放脉冲。

## 方案 B：徽章鼻旁高光 / 解锁演出

白点不再烘焙进徽章 PNG，改成运行时的小星星/闪光：

- 徽章列表：静态干净，不显示白点；
- 解锁弹窗/成就提示：在猪鼻左侧播放 1–2 次星星闪烁；
- 徽章详情：鼠标悬停时轻微亮一下，不做循环闪烁；
- 不使用高频闪烁，频率低于 3 Hz；减少动态时直接不播放；
- 如果后面决定不要白点，也可以完全删除，只在解锁时用粒子替代。

## 数据与代码边界（预留）

建议新增：

- `src/client/pig-expression.js`：叠层创建、锚点解析、播放/停止；
- `src/client/badge-sparkle.js`：徽章解锁星星；
- `packages/pet-core/src/data/expression-anchors.js`：默认锚点表（可选，按 art key）；
- `docs/guides/adding-features.md` 增加“表情叠层”一节；
- 素材侧只增加元数据，不增加新 PNG。

不改：

- 存档结构、数值、玩法；
- 现有 `art-assets.js` 的 key/路径；
- 徽章解锁条件；
- DSH/桌面协议。

## 性能与验收

- 目标 60fps，叠层只做合成层动画；
- 页面隐藏、猪隐藏、扩展打开时暂停；
- Windows 低配/125% 缩放单独看一次；
- 验收要录屏逐帧看渐入渐出和切换皮肤，不只看截图；
- 至少覆盖：默认猪、一个皮肤、一个形态、一个徽章弹窗、减少动态、关闭开关。

## 分阶段

1. **P0 静态清理（当前）**：去腮红、去白点，保持现有画面干净。
2. **P1 默认猪腮红叠层**：只做 `pet` / `feed` / `play` 三个触发，默认猪验证。
3. **P2 徽章星星**：解锁弹窗/提示先做，不动徽章列表。
4. **P3 皮肤/形态锚点**：按皮肤包补 `expression` 元数据，逐步覆盖。
5. **P4 设置与减少动态**：开关、强度、低配回退。

## 需要用户后面拍板

- 腮红是“一直淡淡存在”还是“只在触发时出现”？
- 白点是彻底删除，还是保留成徽章解锁星星？
- 徽章演出放在解锁弹窗，还是徽章列表也做悬停？
- 哪些动作触发腮红：摸摸/喂食/玩耍/升级/生日/生病？
- 是否需要给自定义皮肤包开放 `expression` 字段？
