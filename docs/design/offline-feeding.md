# 离线自助餐与撑不住（0.36.2，返工3 2026-10-14 改）

按 2026-10-13 热修任务单实现，2026-10-14 用户拍板扩成三类并加上「撑不住」的后果。

- 结算间隔超过已有在线礼包的轮询界限 30 秒，视为离开；正常在线轮询不自动消费。
- 三类需要，阈值照搬各自「该照料了」的那条线（`core/views.js` 的 `mood()` 用的就是这几个）：
  - 饱食 ≤ `THRESHOLDS.hungry`（25）→ 吃一份食物（`kind: food`，按 `satiety` 计）
  - 清洁 ≤ `THRESHOLDS.dirty`（35）→ 用一份洗浴用品（`kind: bath`，按 `cleanliness` 计）
  - 心情 ≤ `THRESHOLDS.lonely`（35）→ 用一个玩具（`kind: toy`，按 `happiness` 计；**免费的默认玩具不算背包里的东西**，玩家没买玩具就不玩）
- 每类的选择规则一样：优先能越过阈值且**最便宜**的；都不够越线时优先回复最多的（同回复按价格）。都走正常照料管线 `applySettledCare`（扣库存、加属性、进入体重的正常结算）。
- 没有独立口渴属性，当前货架没有饮料，不新增属性或商品。不吃药、还魂丹、鱼饵、王冠等不能照料的东西。
- 复用照料函数，保留体重、心情、成长、喂食计数、日记计数及过饱判断；结算内只应用已推进到时刻的照料，不能递归调用时间推进。玩家外出活动中的离线时间也可以吃，手动喂食的外出限制照旧。
- 回来时汇总一次「你不在的时候，猪猪自己吃了 苹果×2、洗了 香皂×1、玩了 悠悠球×3」；食物吃完时显示「背包里没吃的了」。同时记日记与记忆。桌面面板尚未创建时，摘要在猪窗口的现有气泡显示，面板已有时也走原有提示条；免打扰照旧。
- 设置沿用现有开关（存档字段 `isOfflineFeedEnabled`），标题暂不改；默认开启，跟随存档。v12 → v13 迁移只添加该开关默认值，已有关闭值保留。

## 撑不住之后（返工3 A2）

- 单次结算的推算上限 = **背包还能喂饱猪多少天 + 10 天**（`core/offline-feed.js` 的 `offlineSustainMs()`），再夹在 400 天的绝对上限（`MAX_SETTLE_SPAN_MS`）内。超出的时间不逐步走，直接给结果。
- 超过上限的时刻（= 没东西撑着超过 10 天）→ **生命垂危**：用现有的健康 1 格表示（`TOO_WEAK_HEALTH`，「太虚弱不能出门」那一档），并发一条提示。累计满 30 天 → `die()`，留下墓碑（`REVIVE_ITEM` 还能救）。
- 「撑」只看食物（用户原话「背包有吃的能撑」）：清洁 / 心情撑不住的后果按现有发病规则走（`onsetRisks()`：脏 → 咳嗽／皮肤，心情差 → 头晕），不另造因果。
- 关掉开关就当作一点东西都没有（玩家自己关的，猪就饿着）。
- 时钟回拨：猪原地不动，等真实时间越过已结算水位（`state.settledUpTo`）才接着只算新增的那一段；不再有「倒退满一天认新时钟」的出口。冻结期间 `decay()` 会打一条 `console.warn`（写明下界与两个时间戳，同一道下界只报一次）——**只有日志，不加界面提示**。

实现注意：饥饿线的分段时间向上取整到毫秒，避免浮点余量使游标不再前进。在线与离线使用同一个结算入口，网页与桌面共用。文案见 `results/fix-offline-clock/文案稿.md`（待用户确认）。
