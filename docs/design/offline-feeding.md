# 离线背包自动喂食（0.36.2）

按 2026-10-13 热修任务单实现，默认规则可由用户调整。

- 结算间隔超过已有在线礼包的轮询界限 30 秒，视为离开；正常在线轮询不自动消费。
- 饱食降到已有饥饿阈值 25 时，从背包吃一份，再按时间继续结算。没有独立口渴属性，当前货架没有饮料，不新增属性或商品。
- 只消费 `kind: food` 且能增加饱食的背包物品；优先选能恢复到 25 以上且价格最低的，没有则选饱食回复最多的，同回复按价格排序。库存不足便继续原来的衰减与疾病结算。
- 复用照料函数，保留体重、心情、成长、喂食计数、日记计数及过饱判断；结算内只应用已推进到时刻的照料，不能递归调用时间推进。玩家外出活动中的离线时间也可以吃，手动喂食的外出限制照旧。
- 回来时汇总一次「你不在的时候，猪猪自己吃了 苹果×2」；没有食物时显示「背包里没吃的了」。同时记日记与记忆。桌面面板尚未创建时，摘要在猪窗口的现有气泡显示，面板已有时也走原有提示条；免打扰照旧。
- 设置使用现有开关，标题「离开时自动吃背包里的东西」，默认开启，跟随存档。v12 → v13 迁移只添加该开关默认值，已有关闭值保留。
- 自动喂食不会自动洗澡、用药或复活，清洁下降和已有疾病照常结算；它避免饥饿风险，不保证已有疾病或其他原因永远不会致死。

实现注意：饥饿线的分段时间向上取整到毫秒，避免浮点余量使游标不再前进。在线与离线使用同一个结算入口，网页与桌面共用。
