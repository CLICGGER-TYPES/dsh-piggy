# 扩展的自动化路线（草案，待用户确认）

> 用户 2026-10-09：「这几个扩展游戏你都最好以增量游戏的想法去设计，这样比较好玩耐玩一点」。
> 这份只是设计，**没写代码**。数字都是初稿，确认方向后再出数值单（J2）并用 `tools/economy-sim.mjs` 校区间。

## 一、几条规矩（跟经济设计一致）

1. **先手动，后自动**：每个扩展一开始都要自己点；自动化要在商店里用扩展币买，一级一级升（跟一键种满一样，增量游戏的路子）。
2. **自动的比手动的慢**：自动化的时薪落在**挂机线**（起步 60～120，满级 800～1200），永远低于自己玩的主动线（300～2500）。自己玩永远更划算，挂着也有进账。
3. **攒满就停，不设每天上限**：自动产出先进一个「仓」，仓满了就不再产，要回来收一下。仓的大小决定「多久回来看一眼」——这就是轻度上头的钩子，又不限制想一直玩的人。
4. **离线也算**：按真实时间结算（跟打工一样），关了游戏回来一次性结清，最多结到仓满。
5. **不碰抽卡**：盲盒、扭蛋不做自动化（自动抽卡等于自动花钱）。
6. **画风**：动森式的「请个帮手」——都是一只小猪帮工 + 一件道具，不做数字面板和进度条墙；界面上只多一行「帮工在干活 · 仓里 23/40 · 收一下」。

## 二、每个扩展

### 矿洞：⛏ 小矿工猪
- 买了以后，小矿工猪在你选的电梯站往下挖，挖到的矿进「矿车」。
- 升级三条线：**镐**（跟你自己的镐共用，越好挖得越快）、**矿车**（仓：容量 30 → 60 → 120 → 240 块矿）、**头灯**（能去更深的电梯站）。
- 初稿：雇佣 3000 矿石币；满级约 1000 矿石币/小时，矿车满级装 4 小时。

### 菜园：🧑‍🌾 帮工猪
- 已有的洒水器管浇水。帮工猪再管**熟了就收、收了就补种**（用你仓库里的种子，没种子就停）。
- 升级：**管几块地**（2 → 4 → 8）、**谷仓**（仓：收的菜放这，满了就不收）。
- 初稿：雇佣 2500 菜币；满级约 900 菜币/小时（不含种子成本），谷仓满级装 6 小时。

### 钓鱼：🎣 自动钓鱼加长
- 现在已经有「让猪自己去钓 30 / 60 分钟」。增量路线是把它升级，而不是另做一个帮工：
  - **鱼篓**：自动钓回来的鱼放鱼篓，加大容量；
  - **时长**：解锁 2 小时、4 小时的自动钓鱼；
  - **鱼饵盒**：自动钓鱼按设好的鱼饵自己补（从背包扣）。
- 初稿：三样各 1500～5000 金币，满级约 600 金币/小时（扣鱼饵）。

### 盲盒、扭蛋
- 不做（见规矩 5）。

## 三、要用户定的

1. 方向对不对：矿洞小矿工猪、菜园帮工猪、钓鱼加长自动钓——三个都做，还是先做一个试手感？
2. **帮工和猪打工能不能同时进行**？能同时：挂机收入叠加（打工 + 帮工），挂机线上限要整体算；不能：猪出门打工时帮工也停。建议：**能同时**，但帮工的产出单独压在挂机线下半段（满级 ≤ 600/小时），合起来不超过 1200 + 600。
3. 仓满要多久：建议 4～6 小时（早上、中午、晚上各看一眼）。

确认后：出 J2 数值单 → 模拟校区间 → 一次做完三个扩展 → 虚拟机验收 → 各扩展发新版本。
