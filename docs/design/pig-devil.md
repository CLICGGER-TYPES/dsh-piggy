# 恶魔猪素材设计

## 已确认的基础造型

基础素材为 `assets/pig-devil.svg`。默认采用战斗眼，左眼旋转 35°；沿用正常猪猪直垂、圆底的腿。身体、鼻子、耳朵和腮红遵守 `ART-SPEC.md` 的配色。蝠翼为宽扇形，远侧翼从背后少量露出；尾巴保留卷曲与酒红色尖端。

基础造型已经由用户确认。新增动作共用这具身体，在动作需要时抬起前蹄、低头或调整翼姿。放松、洗澡和摸摸使用闭眼表情。

## 预览与状态

用浏览器打开 `tools/pig-devil-preview.html`。主预览和玩耍、旅行卡片使用连续路径变形扇翅；其余动作以轻量动画演示。页面支持暂停与减少动态效果偏好。

十份 SVG 均采用原生 64×64 透明画布，使用路径与基础图形平涂，不包含位图、字体、渐变或滤镜。描边仅用于耳朵和尾巴的圆头线条。

## 进化规则与接入

Lv40 起，武力 ≥20、魅力 ≥20、本代成功玩耍 ≥20 次。冷却期间、外出或死亡时被拒绝的玩耍不计数。当前心情不是门槛，变身之后心情变化不会导致退化。

**入口是恶魔契约**：商店「✨ 晋升」货架卖「😈 恶魔契约」；买下来之后在背包里点「签约」完成变身。条件不齐就不签，**道具留在背包不消耗**，拒绝信息会说清还差哪一条。

形态表（`data/evolution.js` 的 `FORMS`）为每个形态写 `via: 'item'` 和对应的 `item` 键。立绘、`hides`、`actionArt` 仍然只有 FORMS 这一份真相。主屏「👑 加冕」App 暂时只显示猪猪王；`crown()` 对恶魔猪诚实拒绝（`needs-contract`）。

条件复用已有 `traits` 和 `stats.plays`；形态记录沿用 `state.form`，无需增加存档字段或版本。新一代重置形态与玩耍次数，复活保留形态；普通成年猪和猪猪王沿用既有规则。

头部和背部装扮在此形态下隐藏，避免和角、蝠翼重叠，拥有与穿戴记录保留。九种日常素材接入既有动作切换与动画；额外飞行素材、连续扇翅路径变形用于独立预览。为了在 64×64 内容纳道具，动作场景中的角色会适当缩小，工作、学习约为基础造型的 73%。

预览页不读写游戏存档。
