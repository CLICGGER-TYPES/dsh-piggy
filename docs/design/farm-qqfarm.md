## 1. 原版是怎么做的（摘要）

### 1.1 画面

![原版构图](../../../design-refs/qqpet/extracted/overview/农场-原版构图拼合.png)

（按原版代码里的地块坐标公式拼的示意，房子、狗窝、篱笆的位置是估的。）

- 一整幅乡村风景做底：远山、水田、大片草地，中间一块大泥地。
- **18 块菱形地，斜 45° 等距排成 3 列 × 6 行**铺在泥地上。开始 6 块熟地，其余 12 块是长草的荒地，第一块荒地上插「扩建」木牌。
- 地有三种样子：熟地（深褐湿土）、旱地（浅黄干土）、荒地（绿草）。
- 右上角是茅草屋、狗窝（有只哈士奇）、一圈木篱笆。
- 顶部：头像、等级和经验条、元宝数、天气图标（晴 / 雨 / 夜晚）。
- 底部工具栏：选择、包袱（种子）、铁锹、浇水壶、除草剂、杀虫剂、手套（收获），再加商店、仓库、我的农场。鼠标变成手上拿的工具。
- 作物每种 7 个状态：种子 → 发芽 → 小苗 → 长大 → 开花 → **成熟** → **枯萎**。地上会冒出杂草、虫子。

### 1.2 规则

| 项 | 原版 |
|---|---|
| 地块 | 共 18 块；开局 6 块熟地；每开垦一块荒地 **10000 元宝**（没有等级限制） |
| 生长 | 种下后按真实时间长，成熟要 14～30 小时；关着也照长 |
| 收获 | 产量 = 基础产量 −3～+2 随机 − 每个灾害 2 个，最少 1 个；收进**仓库**，可单卖或全卖 |
| 枯萎 | 收完地上留枯萎作物，要用**铁锹铲掉**才能种下一株 |
| 灾害 | 每块在长的地，平均约 **4 小时**一次（按指数分布）各自可能**长草**、**生虫**、**干旱**；三样互相独立，可以同时有 |
| 照料 | 浇水（治干旱）、除草、杀虫，**免费**，每次 +2 经验 |
| 天气 | 6～18 点随机晴天或雨天（雨天不会干旱）；晚上显示「夜晚：小心小偷」——但**偷菜没做** |
| 等级 | 升下一级要「当前等级 × 100」经验；收获给作物的经验；种子按等级解锁 |
| 化肥 | 普通 / 快速 / 急速：多长 2 / 3.5 / 5 小时，500 / 800 / 1000 元宝 |
| 多季作物 | 数据里南瓜、橘子、柚子标「二季」，石榴、椰子标「三季」，但**代码没做**，收一次就枯萎 |
| 狗 | 有狗、狗窝、狗粮（含 7 天装）的图，**玩法没做** |
| qqpet 加的 | 一键收获 / 一键照料 / 一键铲除 / 一键播种（免费）；猪在桌面上提醒「农场有 N 块地熟了 / 长草生虫干旱了」，30 分钟内不重复，点一下直接打开农场 |

## 2. 我们现在的菜园（3.0.0）

- 8 块地（开垦价 0 / 0 / 500 / 1200 / 2500 / 5000 / 10000 / 20000 菜币），16 种作物，5 分钟～12 小时一熟。
- 每个阶段要浇一次水，不浇不长；没有灾害、没有枯萎、没有等级。
- 一键浇水 / 收获 / 种满要先花菜币买大水壶、收割镰、播种器解锁；洒水器装在地上自动浇水；肥料让这一季快 30%。
- 帮工猪（K1）：雇了自动收菜、补种、浇水，有管地数和谷仓上限。
- 用自己的「菜币」，和金币 1:1。动森风画面，玩家自己的猪站在菜畦旁边。

## 3. 4.0 改成什么样

### 3.1 照原版的

1. **18 块地**：开局 6 块，其余 12 块是荒地，每块开垦 10000 菜币，不限等级。
2. **原版 20 种作物和全部数值**：成熟时间、产量、单价、经验、解锁等级都照第 1.3 节；菜币就当原版的「元宝」。
   - 对照我们的经济：一块地每小时净赚约 20～29，开局 6 块约 150 菜币 / 小时，和现在 6 块地差不多；全开 18 块约 450 / 小时，但要先花 12 万菜币开垦。
3. **生长不用浇水了**：种下按真实时间自己长，关着照长。浇水只用来治干旱。
4. **灾害**：长草、生虫、干旱，概率和减产照原版（平均 4 小时一次，每样减产 2 个）。照料免费，+2 经验。
5. **天气**：白天每天随机晴或雨（雨天不旱），晚上是夜晚，显示在顶上。
6. **等级和经验**：照原版，升级要「等级 × 100」经验，种子按等级解锁。
7. **枯萎和铲地**：收完留枯萎作物，要铲掉才能再种。
8. **仓库**：收获先进仓库，可以单卖、全卖。
9. **化肥 3 种**：多长 2 / 3.5 / 5 小时，价格 500 / 800 / 1000 菜币。
10. **猪提醒**：菜熟了、地里有灾害时，猪在桌面上说一句，30 分钟内不重复；点气泡直接打开菜园。

### 3.3 旧存档怎么过渡

- 已开的地照旧算开过的（现在开了 8 块的，4.0 里前 8 块都是熟地）。
- 地里正在长的作物：按旧规则长完，收的时候按旧价格进仓库，之后变枯萎。
- 种子库存：29 种作物都保留，旧种子照旧能种（按新数值长）。
- 菜币、谷仓里的东西、帮工猪的等级原样保留。
- 等级从 1 级开始；按以前累计收获的数量折算一点经验（具体数字到实现时再给）。

### 3.4 大小农场（G 的细节，用户 2026-10-12 定）

1. **小农场 6 块地**：正好是大农场开局的 6 块熟地。
2. **两种界面，同一份数据**：玩家在设置里选用大农场还是小农场，体验不同，地、作物、仓库、等级、菜币、帮工猪都是同一份。
   - 大农场：单独的横向大窗口，照原版布局，18 块地、开垦、全部工具都在。
   - 小农场：装在现在的面板里，显示前 6 块地；开垦要切到大农场。已经开了第 7 块以后的地，小农场里用一行字报「另外 N 块地：几块熟了、几块有灾害」，一键操作（买了工具的）对全部地生效。
3. 大农场单独开窗口要升桌面外壳（和全屏隐藏的外壳改动一起发，只升一次）。网页版 / DSH 插件里大农场在页面里铺开显示。
