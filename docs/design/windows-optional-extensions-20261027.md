# Windows安装器可选扩展方案

用户2026-10-27要求新Windows安装器提供扩展可选附加项。交互样稿：/zyx/agents/codex/deliverables/piggy-review/windows-installer-20261027/index.html。

范围：现有NSIS安装目录页之后提供五个默认不勾选的选项：菜园、矿洞、盲盒、扭蛋、藏猪方块；内置番茄钟/钓鱼不重复列。经典菜园是同key兼容变体，继续手动导入，不同时自动装两份。

行为方案：选择随包离线提供；安装器只放扩展包与选择记录，不改游戏存档。游戏单写入Worker走既有导入接口，未孵化延迟到孵化后；已有扩展版本和数据保留，只补装缺失项，未勾选不删除。重复启动幂等，安装器升级不再次补回用户之后主动删掉的同一安装批次扩展。

交付：保留此前冻结RC4文件，新增候选单独目录保存。用户已确认本方案，并指定扩展随安装包、上传夸克。本轮构建完整安装器，不以Gitee单附件100MiB限制阻塞，也不删必要Electron渲染组件凑容量；公开GitHub/npm/Gitee发行另行验收。

验收：全不选、单选、多选、断网、首次孵化、已有扩展保留、重启/升级保档、取消安装和卸载保留数据；接口测试不能代替最终Windows原生安装。只运行一台自建测试VM，给宿主保留8GiB预算，内存不足立即停止自有测试。

当前实施范围（2026-10-27用户最新指示）：20/21已合并，本轮做到Windows完整安装器与五个离线可选扩展构建/验收，不发布新RC、不上传夸克；后续交付另议。构建入口 `npm --prefix apps/desktop run dist:win:offline`。
