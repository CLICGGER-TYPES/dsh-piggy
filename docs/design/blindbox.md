# 盲盒扩展 2.0

> 2026-10-05 · 状态：**已确认**。用户：「盲盒设计要跟明日方舟那样」。数字见 `docs/numbers/X1-blindbox.md`，代码 `extensions/blindbox/`。
> 第一个从「在线扩展」下载的扩展（格式见 `docs/design/extension-download.md`）。只出摆件；装扮没有图，先不碰。

## 1. 玩法一句话

花金币（或盲盒券）在**常驻寻访**或**限时寻访**里开盒 → 抽到 3★～6★ 的摆件 → 重复的加潜能、给资质凭证 → 凭证在商店换东西。50 抽没出六星以后，六星概率每抽往上涨，第 99 抽一定出。

## 2. 卡池

- **常驻寻访**：一直开，每 14 天换一组 UP（1 个六星 + 2 个五星）。
- **限时寻访**：每 14 天换一个主题（农场 → 海边 → 深夜食堂，以后加主题只更新扩展），UP 的六星占 70%。
- 两种卡池的保底计数分开算。轮换按日期算，不需要服务器。

## 3. 开盒（照方舟的节奏，用盒子）

- **单抽**：补给箱落下来摇两下 → 箱缝透出光，颜色先告诉你星级（3★ 灰白、4★ 紫、5★ 金、6★ 橙）→ 五星和六星多一道光柱 → 打开，摆件站上同色底座，星星一颗颗亮起；六星撒彩纸。
- **十连**：两行小箱子一起落下、各自透光，然后每 0.25 秒翻开一个；右上「跳过」一下全部翻开；最后一行总结「新的 N 个 · 资质凭证 +X」。
- 面板每几秒重画一次也接着播（动画时间写成 CSS 延迟），点「收下」才回到卡池。

## 4. 界面

- **寻访**：金币、盲盒券、资质凭证三个小标签；两张卡池卡片（深色底，UP 摆件发光，「还剩 N 天」，保底进度），按钮「用券寻访 / 寻访 1 次 / 寻访 10 次」。
- **展示柜**：按星级分区（六星在上），每个摆件有星级色底座和 6 格潜能，没得到的是剪影；点一下看介绍。
- **凭证商店**：盲盒券、指定一个没有的五星 / 六星、豪华大餐、百草丹。

## 5. 存档

- 扩展自己的数据 `state.extData.blindbox`：每个摆件的潜能、资质凭证、两个保底计数、总抽数、上一次的结果。
- 1.0 的数据（按系列）读的时候自动换算一次，见确认单第 7 节。
- 删除盲盒：清掉上面这些和背包里的盲盒券。

## 6. 发布和更新

- 文件挂在本仓库的 GitHub Release `ext-blindbox-<版本>`（预发布、不标最新）；`node scripts/extension-entry.mjs blindbox` 生成目录条目，写进 `extensions/registry.json`（`main` 和开发分支都要更新）。
- 装了旧版的玩家，在「扩展」App 的盲盒卡片上会看到「更新到 x」，更新后数据保留。
