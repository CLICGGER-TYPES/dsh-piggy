# 成就列表筛选与排序

在成就数量增加后，帮助玩家查找未完成目标，并在浏览详情时保留列表位置。提供全部／已获得／未获得筛选、快达成排序，复用现有徽章和分段按钮。

- 默认「全部 + 分类排列」，保留现有分类与分类内顺序。
- 筛选只看 `acquired`，不把进度满但未结算的项目当成已经获得。标题保留全图鉴已获得数，列表单独显示筛选后的数量；无结果时保留控件并说明原因。
- 「快达成优先」跨分类按 `progress / target` 降序，比例限制在 0–1；已获得项目排在未获得之后，同进度及已获得项目维持原顺序。禁用或卸载的扩展仍沿用原有可见性与详情提示。
- 筛选、排序改变时回到列表顶部。进入详情前记下列表位置，详情从顶部开始；返回时恢复筛选、排序、滚动位置和原徽章焦点。列表缩短时由浏览器把滚动位置限制在可滚动范围内。
- 状态存在当前面板实例里，轮询和详情重绘不清空；刷新页面或重新挂载后恢复默认。不写入游戏存档或本机持久设置。
- 列表仍使用最新快照；浏览详情期间获得徽章后，返回「未获得」会移除该项，不保留过期结果。

开发验证：成就／图鉴／bundle 相关 17 项测试通过（含详情期间解锁后的实时筛选），构建和全仓类型检查通过；隔离浏览器实际验证 34 项中筛出 24 项未获得、10 项已获得，排序前两项为 9/10、8/10；详情往返滚动位置均为 959.2857px，所查浏览器错误日志为空。此为开发预览，不代表 DSH 或 Electron 安装包发布验收。

提交前全量测试：2795 项中 2789 通过、5 跳过、1 失败。唯一失败为未修改的 `test/unit/host/ext-asset-routes.test.js` 在创建测试符号链接时收到本机 Windows 的 `EPERM`，未运行到该链接的路由断言；未跳过或改写该测试，双平台完整结果以 PR CI 为准。
