# 原GIF摸摸效果

状态：2026-10-21 随 0.37.1-rc.5 测试版发布。用户连续反馈重制动作与原GIF的灵动感不同，因此停止重新解释动作，改为直接播放用户提供的原GIF五帧。

## 当前实现

原GIF是112×112、五帧，每帧60ms。解码为560×112无损WebP图集，每格RGBA与原GIF逐像素一致；运行时先用createImageBitmap拆格，避免放大时邻格边缘串色。每一帧使用同一个目标矩形[100,76,280,280]，不再额外变形、旋转、重排或变速。该图集包含手与猪，是完整原效果，不是分层手图或高清重制。

按住普通无装扮小猪循环播放，松手完成当前一轮；面板摸摸播放一轮。关闭小手时，使用游戏原idle.png仅轻微下沉回位。其他形态与高优先级状态保持原逻辑。手感关闭、减少动态、拖动、状态切换和页面隐藏均能取消。

循环不额外发送养成操作。直接点击已播放标记只保存在该请求的客户端选项里，延迟成功回执不会重播。结束时先恢复当前立绘再撤遮罩，避免旧摸摸反应闪回。

## 来源与验证

源GIF从用户保存的HTML内嵌数据提取，研究副本是research/blender-piglet-20261020/reference-motion-20261021/user-reference.gif。没有重新绘制任何源帧。图集只有10,368字节，五格无损解码一致；哈希和参数见assets/animations/piglet-pet/manifest.json，来源见PROVENANCE.md。旧v03–v06保留研究备份，不再加载。

Chromium真实指针测试连续20帧：实际画布与原GIF帧以同样目标矩形绘制的RGBA差异全部为0；帧序与循环保持原60ms节奏（受屏幕刷新量化），连点、松手、拖动取消与减少动态均通过，页面错误0。小手关闭路径保留原立绘。构建、类型检查与1311项自动测试通过。

Linux Electron使用隔离存档；Windows/macOS本轮未验证，不宣称原生逐帧录屏通过。用户已授权发布测试版。日历 / 礼物点击误触摸摸的反馈尚未复现，继续跟踪，不能视为修复。
