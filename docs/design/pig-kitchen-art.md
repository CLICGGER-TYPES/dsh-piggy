# 千奇百怪的小猪：画图规范与验收标准

状态：**规范已定，图未画**（2026-10-07）。画图交给 codex 等 agent 或画师，**每张图最后都要用户过目确认**才能进 `assets/`。
玩法（这些猪拿来做什么：图鉴收藏、扭蛋、皮肤……）另定，本文只管图。

## 1. 要画的是什么

受 Google Emoji Kitchen 启发：**整只 🐖（侧面全身）和一个 emoji 主题「融合」**，比如西瓜猪、幽灵猪、宇航员猪。
Emoji Kitchen 只有 🐷 猪脸、没有整只猪，而且它的图是 Google 的、没有开源许可——**只能借它的点子，不能照描它的图**。
它的 365 种 🐷 组合总览放在维护者本机（`/zyx/DSH/workspaces/dsh-piggy/research/emoji-kitchen/`），只当灵感看。

## 2. 许可（最重要，违反就整张作废）

- **底图只能用 `assets/piglet.svg`**（参照 Noto Emoji 🐖 重绘，Apache 2.0，见 `THIRD-PARTY.md`）。
  新图都在它上面改，所以同样是 Noto 的衍生作品，按 Apache 2.0 发布。
- **主题部分（花纹、帽子、道具、变形）必须自己画。** 禁止：
  - 照描或拼贴 Emoji Kitchen 的图；
  - 用别的 emoji 素材库的图形（Fluent、Twemoji、OpenMoji、Apple、Samsung……），哪怕许可宽松也不用——风格不统一，许可也要另算；
  - AI 生成的图（位图、来源说不清）、网上找的图描摹。
- 每个文件开头写注释：`<!-- 基于 assets/piglet.svg（Noto Emoji 🐖 衍生，Apache 2.0）改画：<主题> -->`。

## 3. 画法规范

### 3.1 技术格式（照 `docs/ART-SPEC.md` 第零节）

- `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 64 64" width="64" height="64" role="img" aria-label="<中文名>">`，带 `<title>`。
- 只用 `path` `circle` `ellipse` `rect` `polygon` `polyline` `line` `g`；身上的花纹要裁在身体里时可以用 `clipPath`。
- **不要**：`image`、`text`、渐变、滤镜、`pattern`、`<style>`、脚本、外部引用。
- 透明底，不画地面和投影。文件 ≤ 6KB，颜色 ≤ 24 种。
- 分组并写 `id`：`body`、`legs`、`ears`、`tail`、`face`、`theme`（主题加的东西都放 `theme` 里），方便以后改色、做动作。

### 3.2 站位

- **侧面朝左**，脚底和 `piglet.svg` 同一高度（±1.5 单位），身体横向中心和它差 ≤ 4 单位——换图时猪不能跳。
- 帽子、道具可以伸出去，但**不能出界**（最外一圈留空，ART-SPEC 建议四周留 2～3 单位）。

### 3.3 风格

- 平涂、零描边；耳朵、尾巴是圆头弧线；眼睛不规则，不是正圆（ART-SPEC 第零节的四条规则照旧）。
- 配色从 ART-SPEC 的猪色板出发；主题色饱和度不要比猪身高太多，放在 `piglet.svg` 旁边不能突兀。
- **一眼认出是猪**：猪鼻子、卷尾、耳朵、蜜桃色身体轮廓四样里至少留三样（「变色」类主题可以换身体颜色，但轮廓要在）。
- **一眼认出是什么主题**：40px 和 24px 下也要看得出（面板里猪就是 40px 左右）。细节少而大，别画小字和细纹。
- 不画血腥、恐怖、宗教、政治、商标（不画某品牌的汉堡、某动画角色）。

### 3.4 融合方式（由易到难，第一批四种都要有）

| 方式 | 例子 | 要点 |
|---|---|---|
| 换色 | 彩虹猪、幽灵猪、机器猪 | 只换身体/腿的颜色，加一两个小特征（幽灵的波浪下摆、机器的铆钉） |
| 身上花纹 | 西瓜猪、草莓猪、斑马猪、奶牛猪 | 花纹裁在身体轮廓里（`clipPath`），眼睛鼻子在花纹上面 |
| 配件 | 宇航员猪、厨师猪、蜜蜂猪 | 帽子 / 翅膀 / 道具，猪本身不变 |
| 变形 | 南瓜猪、云朵猪、甜甜圈猪 | 身体换成主题的形状，保留鼻子、耳朵、尾巴、腿；最难，最容易「不像猪」 |

## 4. 交付与验收

### 4.1 怎么交

1. **先交主题清单**（中文名、对应 emoji、融合方式），用户圈定后再画。第一批建议 20 个，用户可增删：
   西瓜、草莓、南瓜、彩虹、幽灵、机器、宇航员、甜甜圈、云朵、火焰、雪人、樱花、蜜蜂、独角兽、蘑菇、纸杯蛋糕、熊猫、斑马、仙人掌、汉堡。
2. 在分支 `art/pig-kitchen` 上画，草稿放 `art-drafts/pig-kitchen/pig-k-<主题英文>.svg`（kebab-case，如 `pig-k-watermelon.svg`）。
   **草稿不进 `assets/`、不合进 main**，用户确认后才挪进 `assets/` 并接进代码。
3. 同时交一个预览页 `art-drafts/pig-kitchen/preview.html`（浏览器直接打开，不联网）：
   - 每张图在 **128 / 64 / 40 / 24px** 四个尺寸各显示一次，奶油色底（`#f8f8f0`）和深色底各一排；
   - 每张旁边放一只原版 `piglet.svg` 作对照；
   - 标出中文名、融合方式、文件大小。
4. 交一张总览 PNG（`art-drafts/pig-kitchen/overview.png`，全部图 128px 平铺），方便在聊天里直接看。

### 4.2 机器能查的（全过才交给用户）

```sh
uv run --with pillow python tools/check-pig-art.py art-drafts/pig-kitchen/
```

查：格式和元素白名单、文件 ≤ 6KB、颜色 ≤ 24 种、没有外部引用、文件头署名、透明底、不出界、脚底高度和身体中心对齐 `piglet.svg`。

### 4.3 人看的（画的人先自查，再交用户）

| 检查 | 怎么看 |
|---|---|
| 是猪吗 | 24px 下还认得出是猪 |
| 是什么主题 | 不看文件名，24px 下能说出主题 |
| 和原版搭吗 | 预览页里和 `piglet.svg` 并排，不突兀（颜色、线条粗细、比例） |
| 规则四条 | 朝左、零描边、眼睛不规则、耳朵是弧线 |
| 不侵权 | 没有照描任何现成图；没有商标、角色 |

### 4.4 用户确认（最后一关）

- 用户看预览页逐张给「过 / 改 / 不要」；改的写清改哪里，画的人改完重新交。
- **只有用户说「过」的图**才挪进 `assets/`。用户没看过的图不进 main、不发版。
- 进 `assets/` 的那次提交里，CHANGELOG 写新增了哪些猪；`THIRD-PARTY.md` 不用改（已经写了「在 piglet.svg 上改画的都属于 Noto 衍生」）。
