# 体型药水

状态：2026-10-21 用户确认规则，候选实现待验收，未发布。

商店药品货架增加五种药水，统一每瓶 100 金币，购买收入背包，使用一瓶消耗一瓶。

| 药水 | 使用效果 |
|---|---|
| 正常药水 | 立即把真实体重设到正常档 |
| 胖胖药水 | 立即把真实体重设到胖档（现有 round / 圆润） |
| 巨胖药水 | 立即把真实体重设到巨胖档（现有 fat / 胖胖） |
| 锁定药水 | 锁定当前胖瘦档位；实际体重、成长、疾病和生死照常结算 |
| 初始药水 | 仅解除胖瘦锁定，恢复按当前真实体重显示，不重置体重、健康或存档 |

用户撤回了锁定疾病、死亡或其他外观的想法，本次仅实现胖瘦锁。锁定期间改体型需先喝初始药水；重复锁定、未锁时解除和已经处于目标体型均不吞药。活动中、未孵化和死亡沿用道具使用限制。

复用现有普通猪、pig-round、pig-fat 图，不拉伸。胖/巨胖各十种动作：idle、eat、pet、relaxed、play、bathe、sleep、study、trip、work。疾病和死亡沿用原状态显示；体型锁不覆盖它们。普通猪原 GIF 小手继续只适用于普通猪，胖/巨胖使用各自已有 pet 图。

沿用已有显示限制：胖/巨胖套图仅用于普通形态及默认皮肤。穿皮肤或特殊形态时不消耗体型切换药，并提示先换回；现有状态页档位名称不改，锁定时显示“已锁定”。

体型药属于独立物品分类 body，前端合并到既有药品货架；不走疾病用药、不混入疾病药的签到、礼包、打工或扭蛋奖励池。网页、桌面本体和面板共用核心规则。复用原有设档倍率：理想体重 1、1.31、1.61 倍，不调整原阈值和代谢参数。

存档仅新增可选 state.bodyWeight.lockedClass（normal / round / fat）；ensureBodyWeight 保留合法值、清理非法值。旧档无此字段时仍按真实体重显示，存档版本保持 v14。

验证覆盖购买扣款、背包数量、耗药、各档体型、锁定后体重变化、解除、重复使用保护、疾病/死亡正常显示、特殊皮肤与活动保护、旧档与重载。真实桌面操作仅在虚拟机进行。
