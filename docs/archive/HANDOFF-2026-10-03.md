## 接手与发布检查

在独立分支/worktree 开发，开工前查 `git status`、`git log` 并同步最新 `main`；不要覆盖另一个 agent 的未提交改动。改功能先写会失败的测试，客户端源码变更后重建并提交 `client.js`，每次跑 `npm run build && npm test && npm run typecheck`。领域随机使用 `core/random.js`；新存档字段用 `ensureXxx(state)`，不要自行提升存档版本。提交不加 AI 署名。合入/推送前确认主目录干净；发版前确认根目录版本、CHANGELOG 小节、标签和 npm 发布策略一致。
