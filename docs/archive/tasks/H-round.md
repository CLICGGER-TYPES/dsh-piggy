## H1 · 盲盒寻访页：按钮重排 + 卡池轮播（只改 `extensions/blindbox/client.js`）

现状问题（用户）：「用券寻访 / 寻访 1 次 / 寻访 10 次」三个按钮挤在一起换行，难看；卡池卡片是死的，要能轮播、动起来。

要做成这样：

```
┌ 🎁 盲盒 ──────────────────────────┐
│ 🪙 94299   🎟 ×2   📜 128           │ ← 一行小标签
│ ┌──────────────────────────────┐  │
│ │ [常驻]  常驻寻访      还剩14天  │  │ ← 轮播卡（一次只显示一个卡池）
│ │   ╭────╮                        │  │
│ │   │ 🐳 │  ╭──╮ ╭──╮              │  │   UP 六星闪卡大、两张五星小
│ │   ╰────╯  │🐬│ │🦊│              │  │   闪卡自动缓慢流光 + 轻微上下浮动
│ │ 六星 2% · 再 38 抽后每抽 +2%     │  │
│ │ ▓▓▓▓░░░░░░░░░░░                │  │ ← 保底进度条
│ └──────────────────────────────┘  │
│           ●  ○                      │ ← 轮播圆点（点了切换）
│ ┌──────────────┐┌──────────────┐  │
│ │ 寻访 1 次     ││ 寻访 10 次    │  │ ← 两个等宽大按钮并排，第二行小字写价钱
│ │   300 🪙      ││   2700 🪙     │  │
│ └──────────────┘└──────────────┘  │
│ 🎟 用盲盒券寻访 1 次（有 2 张）      │ ← 有券时才出现，整行、金色描边次按钮
└────────────────────────────────────┘
```

细节：
- **轮播**：两个卡池（常驻、限时）做成横向轮播。每 6 秒自动切到下一个（鼠标停在卡片上时暂停）；卡片下面两个圆点可以点；支持左右滑动（pointerdown/pointerup 横向位移 > 40px 切换）。切换动画：整卡横向滑动 + 淡入，0.35s。当前卡池记在模块变量里，面板每几秒重画也不能跳回第一个、不能重播滑入动画。
- **动起来**：UP 闪卡用原型里的闪卡样式（`https://claude.ai/artifact/RNCGDUfXmp4KTL8GCjYd4Z` 的 `.holo`：星级色外框、彩虹流光层、娃娃凸出带阴影）；流光层用 CSS 动画自动缓慢扫过（6 秒一圈），娃娃上下浮动 3px（3 秒一次），三张卡浮动错开相位。限时卡池底色用浅粉渐变（`#fff0f4 → #fffbe7`），常驻用奶油色。`prefers-reduced-motion` 时都不动。
- **按钮**：底下按钮跟着当前轮播到的卡池走（点「寻访 1 次」寻访的是当前显示的那个卡池）。两个主按钮等宽并排（grid 两列），按钮里两行：上面「寻访 1 次 / 寻访 10 次」，下面小字价钱；金币不够时置灰并写「金币不够」。有盲盒券时下面多一整行「🎟 用盲盒券寻访 1 次（有 N 张）」。
- 开盒动画（单抽 / 十连）、页签「展示柜」「凭证商店」本任务**先不动**（H2 会删掉这两个页签）。
- 验收：桌面版和网页版截图，按钮一行两个不换行；轮播自动切换、点圆点切换、滑动切换都能用；重画不跳。

## H3 · Linux 收起面板时拖不到屏幕另一半（只改 `src/client/desktop/*`）

原因（Claude 查过）：收起时窗口仍按「上次面板朝哪边开」预留面板高度（`measure.js` 里 `openBoxes[key]` 那一段），猪固定在窗口一头；Linux 窗口管理器把窗口夹在屏幕内，猪就只能在屏幕的一半里拖。Windows 不夹，所以没问题。

改法：
1. **开始拖时**（`desktop/index.js` 的 `__dshPiggyShell.beginDrag`）：面板收着的话，先进入「紧凑」状态——`measure.boxes` 在紧凑时**不加** `openBoxes` 的预留框（气泡预留区照留），立刻 `tick()` 一次让窗口缩到只包住猪和气泡，再把缩完后的猪位置交给 `shell.beginDrag`。
2. **松手时**（`endDrag`）：退出紧凑；按猪现在的屏幕位置重新选收起时的朝向：看 `openBoxes` 里两种朝向（`bottom|…` 面板在上、`top|…` 面板在下）各需要的高度，上面放得下就用「面板在上」，否则下面放得下就用「面板在下」，都放不下保持原样；设好 `measure.state.vertical` 后 `tick()`。
3. 面板打开时的逻辑不动。
4. 测试：`test/` 里给 measure 加纯函数测试（紧凑时不含预留框；选朝向的规则）。桌面实测：猪放在屏幕下方、收起面板，拖到屏幕最上面能过去，松手后右键打开面板，面板朝下开、不闪。

## H4 · 扭蛋扩展（新，`extensions/gacha/`）

数值单：`docs/numbers/X2-gacha.md`。参考：Hack Club 的扭蛋机（摇机器、转把手、胶囊弹出，只借手感）；不用任何付费素材。

- 一台扭蛋机（扩展 App「扭蛋」），三个口味可选（零食 / 杂货 / 药箱），按数值单的池子出**现有物品**（`api.give` 放进背包）。
- 界面：奶油底；中间一台用 CSS 画的扭蛋机（透明圆罩里一堆彩色胶囊、底座、右边把手、出口）。点「扭一次」：把手转一圈（0.6s）→ 罩里的胶囊抖动 → 一颗胶囊从出口滚出来（颜色 = 稀有度：白普通、蓝稀有、金超稀有）→ 点胶囊（或自动 0.6s 后）上下两半分开 → 物品弹出，写名字和「放进背包」；金色胶囊加一圈闪光。
- 十连：一次掉 10 颗排成两行，依次打开，可跳过。
- 每天第一次免费；幸运值：每扭一次 +1，满 20 下一次必出金色，出金色清零（界面上写「再 N 次必出金色」）。
- 删除扩展：清掉它的数据（幸运值、今天的免费次数、记录）。

## H5 · 种菜扩展（新，`extensions/farm/`）

数值单：`docs/numbers/X3-farm.md`。参考 Farmhand 的玩法思路（GPL，只看不抄代码）。

- 扩展 App「菜园」：上面一块土地，地块按 2×3 排（一开始 2 块，其余上锁写「🔒 N 🪙 开垦」）。
- 种子在**商店的扩展货架**「种子」里买（用 H2 的 shelf 口子，`currency` 用金币：`{ label:'金币', emoji:'🪙', balance }`，买的时候扩展自己 `api.spend`）。种子放在扩展自己的仓库里。
- 地块状态：空地 → 点「种」选种子 → 发芽 → 长大 → 成熟（四个阶段，emoji 分别是 🟫、🌱、🌿、作物本身）。**按真实时间长**，离线也算（记种下时间、浇水时间）；每个阶段要浇一次水（土是干的会写「渴了」，干着的时候不长）；成熟后放着不会坏。
- 收获：作物进扩展仓库；仓库里每样可以「卖」（`api.earn`）；能对应现有食物的可以「放进背包」（`api.give`，对应关系见数值单）。
- 猪会说话：收获时 `api.say`。
- 图鉴分区（H2 的 dex 口子）：「作物」，拿到过的作物点亮。

## H6 · 挖矿扩展（新，`extensions/mine/`）

数值单：`docs/numbers/X4-mine.md`。参考原版 Motherload 的规则（往下挖、越深越值钱、回地面卖矿、升级），代码全部自己写。

- 扩展 App「矿洞」：一块 6 列 × 8 行的格子地图（当前层），顶上一排是地面。每格是土 / 石头 / 硬岩 / 矿 / 梯子（往下一层）/ 化石。没挖开的格子是盖着的（只露出土的颜色，看不出里面是什么），挖开才知道。
- 点一个和已挖开区域相邻的格子就挖：每次挖消耗 1 体力，土 1 下、石头 2 下、硬岩 3 下（镐子升级后少挖几下，见数值单），挖的时候格子裂开、碎屑飞一下。
- 挖到矿进背包（扩展自己的矿石袋），回到「地面」可以卖（`api.earn`）；挖到梯子可以进下一层（层数越深，矿越好、硬岩越多）；化石和宝石是收藏品，进图鉴分区「矿石」。
- 体力：每天满 30，每 10 分钟回 1 点；体力用完写「累了，歇会儿再挖」。
- 商店扩展货架「矿工用品」：镐子升级（3 级）、体力饮料（回 10 体力）。
- 每层地图用「层数 + 日期」做种子随机生成（同一天同一层地图一样），挖过的格子记在扩展数据里。
