- 体重、体型、理想体重合成**一行**：`⚖️ 体重 1.6 kg · 圆润（理想 1.4 kg）`，下面一条细进度条标出理想 / 圆润 / 胖胖三个点。体型叫法统一成「正常 / 圆润 / 胖胖」（现在一处写圆润/胖胖、一处写胖胖猪/大肥猪）。
- 去掉「陪伴」行。
- 等级说明重写：等级 + 称号 + 经验进度条 + 下一个称号还差多少 + 一句「成长值怎么来」（照顾、打工、上学等，按代码里的实际来源写）。
- 喂食 / 洗澡 / 玩耍改成**跳到背包对应货架**（食物 / 洗浴 / 玩具）；摸摸没有物品，留在原地直接摸。
- 「称呼」「改名」挪到居民卡；「免打扰」挪到设置。

### 2. 背包
- 顶部加一条状态：饱食 / 心情 / 清洁 / 健康四个小条 + 体重。
- **背包里用食物、洗浴、玩具，和以前状态页的喂食走同一条路**：长体重、会胀气、猪会说话、玩耍会减重（现在背包里直接用这些都没有）。免费的小皮球出现在玩具货架里。

### 3. 签到改 7 天
- 出数值确认单 `docs/numbers/G1-signin-7.md`（7 天奖励，由低到高，第 7 天大礼；原 12 天里的还魂丹等怎么安排写清楚），用户确认后再改。
- 老存档：正在第 N 天（N > 7）的，按确认单里定的规则换算（建议：直接回到第 1 天，并补发一份第 7 天礼包，不让人吃亏）。

### 4. 数值调整（先出确认单 `docs/numbers/G2-care-balance.md`）
目前的问题和建议方向：
- 吃东西变脏：肉骨头、蛋糕、烤串、豪华大餐等会扣 4～10 清洁 → 建议食物**一律不扣清洁**；
- 洗澡扣饱食、玩耍扣清洁：建议保留但减半（玩累了出汗合理，扣得少一点）；
- 胃胀气：现在喂之前饱食 ≥95 就有 25% 概率 → 建议只有**已经 100% 还硬喂**才可能胀气，概率降到 15%；
- 心情：每小时掉 3.6、低于 30 会提高生病概率 → 建议掉速降到每小时 2.4。
具体数字以确认单为准，不确认不改。

### 8. 对话与互动
- 台词翻倍：现有 29 个场景约 100 句 → 每个场景至少翻倍，并补上钓鱼、商店、出门旅行等没有台词的场景；先出台词表给用户看（同以前 B6）。
- 按时间说话：早上、中午、深夜问候，提醒喝水、休息，节日问候（节日表一并给用户确认）。
- 摸不同部位：按点在猪身上的位置分头 / 肚子 / 耳朵 / 尾巴 / 脚，各有动作和台词；连续摸太多会不耐烦。
- 猪主动找事：无聊时原地打滚、打盹、追蝴蝶等小动作；桌面版「出去散步」（沿屏幕底边走一段再回来）设置里打开，默认关。
- 顺手去掉一次操作同时冒两句话的问题（客户端反应台词和核心台词重复）。

### 9. 钓鱼界面重做
- **已定（用户 2026-10-05）**：原型 `docs/prototypes/fishing-fight.html` 里的三种搏斗玩法（A 圆盘、B 竖条拉锯、C 拉力收线）**都要**；每次鱼咬钩后随机用其中一种。抛竿前、等咬钩、结果页用原型里的新设计。
- 先出 2～3 个可点的 HTML 原型给用户挑，再改代码。参考：Stardew 式钓鱼条（MIT 的 FoundryVTT 钓鱼小游戏可直接借 UI 写法）、现在的圆盘改进版。

- 原版 QQ 宠物的挖矿、钓鱼等小游戏只用来体会规则手感，不用任何原版素材。
